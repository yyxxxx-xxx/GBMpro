#### GBMKnowledgeBase（知识库层）

**职责**：管理GBM领域多模态知识，提供靶点信息查询、临床洞察检索和分子参考。

**核心代码**：定义`GBMTarget`、`GBMClinicalData`、`GBMMolecule`三个数据类和`GBMKnowledgeBase`管理类。

**数据接口**：
```python
# 加载靶点信息
target = kb.get_target_info("EGFR")  # 返回GBMTarget对象
# 随机选择靶点（按权重）
target = kb.get_random_target({'EGFR': 0.25, 'VEGF_VEGFR': 0.20, ...})
# 获取相似分子
mols = kb.get_similar_molecules("EGFR", limit=5)  # 返回GBMMolecule列表
# 获取临床洞察
insights = kb.get_clinical_insights()  # 返回字典含challenges/failed_insights/successful_patterns
```

#### GBMPromptGenerator（Prompt生成层）

**职责**：将GBM知识转化为结构化的自然语言Prompt，注入给Llamole模型。

**关键方法**：
- `generate_full_prompt()`: 生成包含CoT推理引导的完整Prompt
- `build_tot_propose_prompt()`: 构建ToT三阶段的结构化Prompt（骨架提议/片段组装/SMILES生成）
- `build_feedback_injected_prompt()`: 将物理评估结果注入到反馈Prompt中

**ToT Prompt模板**（`english_gbm_prompts.yaml`中的`tot_design_nodes`）：
```
Stage 0 (Scaffold Proposal):
  "[FORMAT] Output EXACTLY this structure for each scaffold, 6 lines max:
   Scaffold 1:
   Name: <name>
   Rationale: <max 10 words>
   Base MW: <N> Da
   BBB Potential: <high/medium/low>
   ..."

Stage 1 (Assembly Strategy):
  "Scaffold: {selected_scaffold}, Base MW: {scaffold_mw} Da.
   Budget: {remaining_mw} Da remaining. Target total: {target_mw} Da.
   [FORMAT] Output EXACTLY this structure for each strategy, 7 lines max: ..."

Stage 2 (SMILES Generation):
  "Design: scaffold={selected_scaffold}, warhead={warhead_type}, enhancers={bbb_enhancers}.
   Target MW: {target_mw} Da (range: 150-700). ...
   MUST contain 2-8 aromatic rings and at least one polar group..."
```

#### GBMGenerator（推理引擎层）

**职责**：封装Llamole模型调用和生成分子结果。

**核心代码**：`gbm_project/src/gbm_generator.py`

**关键方法**：
# 主生成流程
results = generator.generate_gbm_molecules(

    use_cot=True            # 是否使用CoT推理

# 单分子生成（含ToT）
mol_data = generator._generate_single_molecule(
    target_name, constraints, use_cot, candidate_id

# Llamole推理调用
generated_text = generator._generate_with_llamole(full_prompt)

# SMILES提取与验证

```

#### GBMPhysicalEvaluator（物理评估层）

**职责**：对生成分子进行Vina对接、ADMET预测和多目标评分。

**四大评估组件**：

**（1）VinaDockingTool**：基于AutoDock Vina的对接工具
```python
tool = VinaDockingTool(
    vina_executable="/path/to/qvina",    # QVina可执行文件路径
    receptor_pdbqt="/path/to/EGFR.pdbqt",  # 受体PDBQT文件
    center=(x, y, z),                     # 对接盒子中心
    size=(20, 20, 20),                    # 对接盒子尺寸
    exhaustiveness=8,                      # 穷尽性参数
    timeout=30                             # 超时秒数
)
vina_score, error = tool.dock(smiles)  # 返回 kcal/mol
```

**（2）ADMETCalculator**：ADMET属性计算器
```python
calc = ADMETCalculator()
result = calc.compute(smiles)
# result包含:
# - dili_prob: DILI风险概率 [0, 1]
# - herg_prob: hERG风险概率 [0, 1]
# - bbb_score: BBB评分 [0, 1]
# - dili_alert_matches: 命中的DILI结构警报
# - herg_alert_matches: 命中的hERG结构警报
```

**DILI结构警报**
| SMARTS模式 | 毒性结构 | 建议替换 |
|-----------|---------|---------|
| `C(=O)Cl` | 酰氯 | 酰胺(-C(=O)NH-) |
| `N=C=S` | 异硫氰酸酯 | 碳酰胺(-NH-C(=O)-) |
| `C1CO1` | 环氧烷 | 内酰胺或饱和杂环 |
| `[cx]1([N+](=O)[O-])ccc1` | 二硝基芳烃 | 磺酰胺 |
| `C1(=O)ccc(=O)c1` | 醌类 | 氢醌二甲醚或环己酮 |
| `OP(=O)(O)O` | 磷酸酯 | 膦酸酯 |
| `[N-]=[N+]=C` | 重氮盐 | 稳定氨基(-NH2) |

**hERG结构警报**（部分）：
| SMARTS模式 | 结构特征 |
|-----------|---------|
| `[cR1]1[cR1][cR1]([N+!0;D1])[cR1][cR1]1` | 含氮杂芳环 |
| `c1ccc2c(c1)cccc2` | 萘环 |
| `[cR1]1[cR1][cR1]([N+](=O)[O-])[cR1][cR1]1` | 硝基芳香族 |
| `c1ccc(C(F)(F)F)cc1` | 三氟甲基苯 |

**（3）MPORewardCalculator**：多目标合意度评分器
```python
mpo = MPORewardCalculator()
is_pruned, reason = mpo.check_hard_cutoffs(result, baseline_dili, baseline_herg)
reward = mpo.compute_reward(
    vina_norm=result.vina_norm,
    dili_norm=result.dili_norm,     # 1 - dili_prob
    herg_norm=result.herg_norm,     # 1 - herg_prob
    bbb_norm=result.bbb_norm,
    tpsa_norm=result.tpsa_norm,
    mw_norm=result.mw_norm
)
```

**硬截断阈值**
| 参数 | 阈值 | 含义 |
|------|------|------|
| `vina_min` | -5.0 kcal/mol | Vina > -5.0 → 剪枝（结合过弱） |
| `dili_max` | 0.95 | DILI > 0.95 → 剪枝（极高肝毒性） |
| `herg_max` | 0.90 | hERG > 0.90 → 剪枝（极高心脏毒性） |
| `mw_min` | 200 | MW < 200 → 剪枝（过小） |
| `mw_max` | 700 | MW > 700 → 剪枝（过大） |
| `tpsa_min` | 20 Å² | TPSA < 20 → 剪枝（水溶性极差） |
| `tpsa_max` | 140 Å² | TPSA > 140 → 剪枝（BBB困难） |

**MPO Reward权重**：
| 指标 | 权重 | 归一化方式 |
|------|------|-----------|
| Vina对接分数 | 0.30 | (-4 - vina) / 8，范围 [-12, -4] → [0, 1] |
| DILI安全性 | 0.20 | 1 - DILI_prob |
| hERG安全性 | 0.20 | 1 - hERG_prob |
| BBB穿透性 | 0.20 | Clark公式 + 惩罚，[0, 1] |
| 理化性质 | 0.10 | TPSA×MW几何平均 |

**（4）GBMPhysicalEvaluator**：整合上述组件的主评估类
```python
evaluator = GBMPhysicalEvaluator(
    vina_executable="/path/to/qvina",
    receptor_pdbqt="/path/to/EGFR.pdbqt",
    vina_center=(x, y, z),
    vina_size=(20, 20, 20),
    reward_weights={'vina': 0.30, 'dili': 0.20, 'herg': 0.20, 'bbb': 0.20, 'physchem': 0.10},
    hard_cutoffs={'vina_min': -5.0, 'dili_max': 0.95, 'herg_max': 0.90, 'mw_min': 200, 'mw_max': 700, 'tpsa_min': 20, 'tpsa_max': 140}
)

result = evaluator.evaluate(smiles, baseline_dili, baseline_herg)
# result.verdict: SURE/LIKELY/IMPOSSIBLE
# result.reward: MPO Reward [0, 1]
# result.build_feedback_text(): 自然语言反馈Prompt
# result.to_dict(): 完整评估数据字典
```

### 2.3.2 临床治疗数据库

**核心内容**：
- **标准治疗方案**：Stupp方案（手术+放疗60Gy+替莫唑胺75mg/m²/d×42天）
- **治疗挑战**：TMZ耐药率达90%、中位生存期仅14.6个月、BBB穿透困难、肿瘤异质性
- **失败临床试验洞察**：单靶点抑制剂失败（通路冗余）、免疫治疗单药失败（免疫抑制微环境）、BBB穿透不足
- **成功治疗模式**：多靶点协同、BBB优化（亲脂性优化/主动转运）、免疫组合治疗、干细胞靶向
- **耐药机制**：TMZ耐药（MGMT修复/碱基切除修复/细胞周期检查点缺陷）、靶向治疗耐药（靶基因扩增/下游激活）、免疫治疗耐药（免疫检查点上调/Treg扩增）
- **分子亚型**：经典型（EGFR扩增/25%）、间充质型（NF1缺失/25%）、前神经元型（PDGFRA/IDH突变/25%）、神经型（神经标记物高表达/25%）

### 2.3.4 分子设计原则

**理化性质约束**（`gbm_molecules.json`第152-160行）：
```
MW范围: 300-600 Da
LogP范围: 1-4
TPSA范围: 60-120 Å²
HBD范围: 1-5
HBA范围: 3-10
可旋转键上限: 8
BBB通透性标准: logBB > -1 或 logPS > -3
GBM选择性标准: GBM细胞/正常细胞毒性比 > 10

### 2.6.2 BBB穿透性预测

**Clark公式**：
```
logBB_est = 0.152 × LogP - 0.0148 × TPSA + 0.139

BBB_score = (logBB_est + penalty + 1.0) / 1.5
# penalty = -0.20 (if MW > 450) + -0.15 (if HBD > 2) + -0.10 (if HBA > 6)
# 映射: logBB > 0.5 → 1.0, logBB < -1.0 → 0.0
```

**CNS药物理化约束**：
| 参数 | CNS药物标准 | 超过时的处理 |
|------|------------|-------------|
| MW | < 450 Da | 警告并扣分 |
| TPSA | < 90 Å² | CNS类药性判断 |
| LogP | 1.0-4.5 | 低于/超过均警告 |
| HBD | ≤ 2 | 超过警告 |
| HBA | ≤ 7 | 超过警告 |

### 2.6.3 毒性风险评估

**DILI评分**（`ADMETCalculator._compute_dili()`，`gbm_physical_evaluator.py`第675-748行）：
```
基础分 = Σ(命中毒性SMARTS × 0.25) + Σ(命中PAINS × 0.05)
MW惩罚: >800 → +0.15, >700 → +0.05
LogP惩罚: >5.5 → +0.10, >4.5 → +0.05
EGFR弹头豁免: 如果命中丙烯酰胺/氰基丙烯酰胺，penalty × 0.25
最终DILI_prob = min(1.0, 基础分)
```

**hERG评分**：
```
基础分 = Σ(命中hERG SMARTS × 0.20)
LogP惩罚: >5.5 → +0.20, >4.5 → +0.10
MW惩罚: >600 → +0.10
碱性氮惩罚: ≥2个碱性氮 → +0.15
EGFR弹头缓解: 如果命中EGFR弹头，penalty × 0.75
最终hERG_prob = min(1.0, 基础分)
```

### 2.6.4 MPO Reward计算

**多指标归一化**：

| 指标 | 原始范围 | 归一化方式 |
|------|---------|-----------|
| Vina | [-12, -4] kcal/mol | (-4 - vina) / 8 |
| DILI | [0, 1] 概率 | 1 - dili_prob |
| hERG | [0, 1] 概率 | 1 - herg_prob |
| BBB | [0, 1] 评分 | 直接使用 |
| TPSA | [0, +∞) Å² | 分段惩罚：>90Å²→逐级扣分，40-90→满分，20-40→0.5-1.0插值，<20→剪枝 |
| MW | [0, +∞) Da | 300-500→满分，<300→线性递减，>500→线性递减 |

**加权几何平均Reward公式**：
```
Reward = exp( w_vina×ln(max(vina_norm,1e-8))
        × exp( w_dili×ln(max(dili_norm,1e-8)))
        × exp( w_herg×ln(max(herg_norm,1e-8)))
        × exp( w_bbb×ln(max(bbb_norm,1e-8)))
        × exp( w_physchem×ln(max(sqrt(tpsa_norm×mw_norm), 1e-8))))

Reward = exp( Σ_i w_i × ln(max(s_i, 1e-8)) )
```

**Verdict判决**：
- Reward ≥ 0.7 → **SURE**（强烈推荐继续）
- Reward ≥ 0.4 → **LIKELY**（有轻微问题但值得探索）
- Reward < 0.4 → **LIKELY**（保留探索机会）
