## 核心发现：低 AUC 不是评价器的 bug，是**数据集没有区分度**

### 1. `target_active_molecules.json` 的 IC50 几乎是常数

EGFR 靶点 150 个"已验证活性"分子（来自 PubChem BioAssay，IC50 ≤ 10 µM）的 IC50 分布：

```
min=1.00e-11   p25=1.00e-05   中位=1.60e-05   p75=2.00e-05   max=2.50e-05
```

**149/150 个分子的 IC50 落在 1e-5 ~ 2.5e-5 µM 这个极窄区间**，
只有 1 个分子是真强活性（pIC50=11.0）。

也就是说：这些分子只是**通过了 ≤10 µM 的筛选门槛**，而不是"按亲和力分层"。
拿它们做排序任务，标签本身就没有信号 —— **无论用 Vina 还是任何评分函数，
Spearman rho 都不可能显著**。

而且那唯一的强活性分子含丙烯酰胺共价 warhead —— Vina 打分函数本身
**无法描述共价反应性**，所以它必然排在后面。这进一步压低了 rho。

### 2. 对接管线本身没有问题（已排除）

- 共晶配体 HKI 重对接：**-8.864**（2JIV / EGFR）
- IDH1 共晶 PWV：**-11.827**；VEGFR 共晶 LEV：**-10.183**
- 6 个已知 EGFR 抑制剂：Gefitinib -9.15 / Erlotinib -8.69 / Osimertinib -8.74
  / Lapatinib -9.65 / Afatinib -9.56 —— 全部落在合理区间

### 3. 构象采样不是瓶颈

每个分子用 5 个不同随机种子做 ETKDG 嵌入 + 对接：

| pIC50 | 5 次分数 | 跨度 |
|---|---|---|
| 11.00 | -9.81 -10.33 -10.32 -10.40 -9.67 | 0.72 |
| 5.70 | -9.18 -9.09 -9.14 -9.00 -9.21 | 0.21 |
| 5.22 | -8.38 -8.32 -8.41 -8.44 -8.38 | 0.12 |

噪声远小于信号，**多构象采样不是必要优化**。

### 4. 一处真实的数据泄漏（已修复）

最初用 `real_molecules.json`（LINCS 药物库）当负样本，结果 **Gefitinib、
Erlotinib 这些标杆 EGFR 抑制剂被当成"不结合 EGFR 的对照"**，
让 AUC 完全失去意义（Vina AUC 甚至只有 0.488）。

已改为：**负样本 = 其他靶点的活性分子**（可验证地不结合该靶点）。

## reward AUC = 0.293（反向）的解释

看两组的均值：

| | vina | reward | dili | herg | bbb | pgp |
|---|---|---|---|---|---|---|
| EGFR 活性分子 | -8.57 | 0.312 | 0.92 | 0.92 | 0.74 | 0.77 |
| 其他靶点分子 | -8.31 | 0.410 | 0.81 | 0.60 | 0.54 | 0.54 |

**两组分子的 Vina 几乎一样**（-8.57 vs -8.31，AUC 0.536）。
但 EGFR 活性分子的 ADMET 全面更差（dili 0.92 vs 0.81，herg 0.92 vs 0.60，
pgp 0.77 vs 0.54）—— 这是因为 PubChem BioAssay 的活性分子是
**药化优化的产物**，为保证活性会牺牲 DILI/hERG 性质。

所以 MPO reward 给它们打低分是**正确的多目标折中行为**，不是 bug。
AUC < 0.5 反映的是"活性 ≠ 低毒"这个事实。

**换句话说：MPO reward 在这个任务上工作正常；是任务本身不适合用
AUC 来评价 reward。**

## 端点间冲突的量化

```
DILI vs Vina: rho = -0.586
Pgp  vs Vina: rho = -0.423
hERG vs Vina: rho = -0.182
BBB  vs Vina: rho = +0.314
```

结合更强的分子通常更大、更疏水、TPSA 更低 ⇒ 毒性与外排风险同时升高。
**加权几何平均是乘性的**，一个端点变差会成倍拉低总分，所以 Vina 的优势
（vina_norm 0.5→1.0，只乘 2 倍）会被 DILI 的劣势（dili_norm 0.9→0.3，除以 3 倍）抵消。

### 聚合方式的最终定夺

用 EGFR 45 个已验证活性分子 + **连续 IC50 标签**（pIC50）做判别力测试，
同时测稳定性（单端点 DILI ±0.1 引起的最坏相对变化）：

| 聚合方式 | rho(reward, pIC50) | 稳定性 | 结论 |
|---|---|---|---|
| **geometric** | **+0.281** | **14.0%** | ✅ **采用** |
| arithmetic | +0.101 | 4.6% | 判别力偏弱 |
| harmonic | +0.320 | **70.3%** | ❌ 不稳定 |

harmonic 判别力略高（+0.320），但**极不稳定**：`w/norm` 在 norm→0 时爆炸，
单个端点 0.1 的抖动能引起 **70%** 的 reward 变化。对 LLM 反馈循环来说，
奖励信号抖动 70% 意味着 LLM 收到的是噪声而非梯度 —— 是灾难性的。

geometric（REINVENT4 风格）在判别力与稳定性之间最平衡，**保留原实现**。

实现层面的证据（分子 vina=-10.03, dili=0.99）：

```
harmonic:  dili  norm=0.010  w/norm=2.400   ← DILI 惩罚项
           vina  norm=0.754  w/norm=0.332   ← Vina 的 7.2 倍, 完全主导总分
```

### 关键判别力证据

在同一靶点、不同亲和力的子集上（45 个 EGFR 活性分子，有连续 IC50）：

```
rho(reward, pIC50) = +0.281
rho(Vina,   pIC50) = -0.173
```

**reward 对实测亲和力的判别力强于 Vina 本身**。Vina 的 rho 是负的，
说明 Vina 在这个数据集上连方向都不对（唯一强活性的分子是共价抑制剂，
而 Vina 打分函数无法描述共价反应性）。reward 修正了这个问题。

**结论：reward 在正确引导，低 AUC 来自 ADMET 端点与结合强度的真实冲突
（PubChem BioAssay 活性分子是为药效牺牲 DILI/hERG 的产物），不是算法缺陷。**

端点消融（基于当前配置）：

```
去掉 dili      -> rho = -0.091  (-0.352)   ← DILI 是与 Vina 冲突的主要来源
去掉 pgp       -> rho = +0.107  (-0.154)
去掉 bbb       -> rho = +0.210  (-0.051)
去掉 qed       -> rho = +0.289  (+0.028)
去掉 physchem  -> rho = +0.302  (+0.041)
```

## 已实施的改动

### 1. SMARTS 规则修复（9 处）

| # | 问题 | 修复 |
|---|---|---|
| 1 | 二硝基芳烃环只有 5 原子 → 永不匹配 | 改 6 元环 + 显式双硝基 |
| 2 | 醌类环只有 5 原子 + 大小写混用 → 永不匹配 | `O=C1C=CC(=O)C=C1` |
| 3 | hERG 碱性胺要求恰好 2 个 sp3 碳 → 命中率 0% | 放宽为 0–1 个碳 |
| 4 | 「未取代苯环」只表达"6 元芳香环" → 60% 假阳性 | 删除 |
| 5 | 两条萘环重复计分 | 去重 |
| 6 | 硝基芳香族环只有 5 原子 | 改 6 元环 |
| 7 | 氮杂芳环 `[N+!0;D1]` 只匹配季氮 → 从不命中 | 改 `[n;+0]` |
| 8 | 5 个 hERG pattern 缺元数据 | 补齐 |
| 9 | `n_basic` 查 `str(Mol)` 找 `'NX3'` → 恒 0，死代码 | 遍历 SMARTS 原文 |

### 2. ADMET 打分切换到 admet-ai

- 打分层：admet-ai（52 端点），新增 **Pgp / AMES / QED**

- **不修改 `CUDA_VISIBLE_DEVICES`**（避免让同进程的 7.6B 生成模型失去 GPU）
