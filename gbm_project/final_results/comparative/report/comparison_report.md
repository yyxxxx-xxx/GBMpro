| 项目 | 配置 |

| 多样性 | Bemis-Murcko 骨架去重数 + 归一化 Shannon 熵 |
| 新颖性 | 与 ChEMBL 的最大 Tanimoto 相似度（越低越新颖） |

> **公平性声明**：所有方法（含基线）均由**同一版本、同一参数**的本地管线重新评测。基线 CSV 中原有的 `vina_docking_score` 来自早期的经验公式伪对接，已被全部覆盖（保留在 `vina_docking_score_legacy` 列供追溯）。

> **类药预筛**：进入对接前，所有方法共用同一道门槛（MW ≤ 500、重原子 ≤ 40、可旋转键 ≤ 10）。该门槛不是为了削弱基线，而是因为极端柔性分子（如 147 个可旋转键的长链烷烃）会让 Vina 的扭转树搜索指数级爆炸而无法完成对接 —— 这类结构本身也不具备成药价值。预筛通过率作为独立指标报告（见 §1.4）。

> ⚠ **关于 REINVENT4 (Vina-RL) 的解读**：该基线在训练时**以真实 Vina 对接分数作为强化学习的奖励信号**（DAP 策略梯度），即它的优化目标与评测指标 Vina 分数是同一个量。因此它在 Vina 上的优势是「用评测指标做训练目标」的直接结果，而非「更好的先验表示」。在论文中它应被视为**对接引导生成（docking-guided generation）的性能上界参照**，而不是与我们的模型在同等条件下的直接对比。把它与我们的方法并列比较时，必须同时说明这一不对称性。同样地，PlayMolecule AI 的分子在 EGFR/VEGFR 上呈现单一骨架（骨架熵 = 0.0），其高 Vina 分数伴随严重的模式坍缩。

> **补充**：REINVENT4 并**没有**出现模式坍缩 —— 三个靶点上均为 20/20 唯一骨架、0% 近重复，因为其 RL 阶段启用了 IdenticalMurckoScaffold 多样性过滤器。因此它在结合能力与化学多样性上同时领先，是本次对比中表现最强的基线，也意味着审稿人更可能追问「为什么不对我们的模型也做同样的对接引导」。请参见 §7 建议第 2 条。

## 1.5 多目标综合排序（结合能力 × 类药性 × 多样性）

单一 Vina 指标不足以评价一个生成分子模型。真实 CNS 药物需要同时满足：与靶点口袋结合、具备类药物化性质（BBB 通透、低 Pgp 底物、低 hERG/DILI 风险）、且化学空间不坍缩。下表把三个维度合成一个0–1 的综合得分（每维度先做 min-max 归一化后等权平均）。

**综合得分定义**：

```
Affinity  = 归一化(|Vina 均值|)           # 结合越强越高
Druglike  = (BBB+ + (1-Pgp%) + (1-hERG%) + (1-DILI%)) / 4
            # CNS 药物需要能过血脑屏障、且无外排/心脏/肝毒性风险
Diversity = 归一化(骨架熵)                    # 骨架熵越高越不坍缩
Composite = (Affinity + Druglike + Diversity) / 3
```
