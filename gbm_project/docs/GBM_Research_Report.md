# 基于多模态大语言模型的胶质母细胞瘤（GBM）新药候选分子生成与优化研究

## 研究报告

---

## 一、研究问题与背景

### 1.1 胶质母细胞瘤的药物开发挑战

胶质母细胞瘤（Glioblastoma, GBM）是成人中最常见、恶性程度最高的原发性脑肿瘤，中位生存期仅 12–15 个月，五年生存率不足 5%。标准治疗方案（手术 + 放疗 + 替莫唑胺化疗）的疗效已触及瓶颈，核心原因在于三个方面：

- **分子异质性**：GBM 存在广泛的基因突变（如 EGFR 扩增约 40%，IDH 突变约 10%）和多条信号通路异常激活，导致"单一靶点、单一药物"策略难以奏效。
- **血脑屏障（BBB）**：超过 98% 的小分子药物无法有效穿透 BBB 到达肿瘤部位，使大量具有良好体外活性的候选分子在体内无效。
- **耐药性**：TMZ 耐药率高达 90%，且复发 GBM 的中位生存期仅 3–9 个月。

因此，GBM 新药发现本质上是一个**多目标优化问题**：同时需要优化靶点结合活性、BBB 通透性、成药性和安全性等多个维度。

### 1.2 核心研究问题

本研究围绕三个核心科学问题展开：

| 问题 | 描述 |
|------|------|
| **Q1：多模态表征对齐** | 如何构建一个能够有效融合分子结构、生物活性数据和药代动力学属性的统一表征空间？ |
| **Q2：多目标可控生成** | 如何引导多模态大语言模型（MLLM）根据复杂多目标约束进行条件化分子生成？ |
| **Q3：可靠性验证** | 如何对生成分子进行快速、可靠的虚拟筛选，筛选出高潜力候选者？ |

## 二、技术方案

### 2.1 系统架构总览

```
用户输入靶点（如 EGFR）
         ↓
┌──────────────────────────────────────────────────────────┐
│              GBMPromptGenerator + GBMKnowledgeBase         │
│  → 从 GBM 知识库检索靶点信息 + 临床数据 + 分子参考库         │
│  → 生成包含靶点描述、分子约束、临床洞察的领域提示词 (Domain Prompt) │
└──────────────────────────────────────────────────────────┘
         ↓
┌──────────────────────────────────────────────────────────┐
│                   Tree-of-Thoughts BFS 搜索                  │
│  Level 0: Scaffold Proposal（骨架提议）k=3 → b=2 保留        │
│  Level 1: Assembly Strategy（组装策略）k=3 → b=2 保留      │
│  Level 2: SMILES Generation（SMILES 生成 + 多轮反馈优化）   │
└──────────────────────────────────────────────────────────┘
         ↓
┌──────────────────────────────────────────────────────────┐
│               GBMPhysicalEvaluator 多维评估                   │
│  Layer 1: RDKit 描述符计算（TPSA / MW / LogP）              │
│  Layer 2: DILI 风险评估（SMARTS 警示结构）                  │
│  Layer 3: hERG 心脏毒性 + BBB 通透性（Clark 公式）          │
│  Layer 4: Vina 分子对接 + MPO Reward 聚合                   │
│  → 硬剪枝（is_pruned=True 的分支直接丢弃）                  │
└──────────────────────────────────────────────────────────┘
         ↓
      最终候选分子（SMILES + 多维度评分）
```

### 2.2 两阶段 LoRA 微调

模型采用两阶段参数高效微调（LoRA），最终以 PeftModel 形式供推理调用：

```
Qwen2-7B-Instruct（基座模型，FP16）
         ↓ [Stage 1: PEFT LoRA]
Llamole Adapter（通用指令遵循 + 图模型支持）
         ↓ merge_and_unload()
合并后基座模型
         ↓ [Stage 2: PEFT LoRA]
GBM Domain Adapter（GBM 领域专业知识 + 分子生成能力）
         ↓
最终推理模型 PeftModel（供 TreeOfThoughtsGenerator 调用）
```

Stage 1 的 LoRA 权重合并回基座后，再叠加 Stage 2 的 GBM 领域 LoRA，两个阶段协同作用：前者保证通用指令遵循能力，后者注入 GBM 垂直领域的分子生成逻辑。

### 2.3 Tree-of-Thoughts BFS 搜索

ToT 搜索将分子生成解构为三层的渐进式搜索树：

| 层级 | 输入 | 输出 | k（生成数） | b（保留数） |
|------|------|------|------------|------------|
| **Level 0** | 领域提示词 + 靶点约束 | 候选骨架（如 quinazoline） | 3 | 2 |
| **Level 1** | 骨架 + 组装策略 | warhead + BBB 增强基团 | 3 | 2 |
| **Level 2** | 骨架 + 组装策略 | 完整 SMILES + 物理评估反馈循环 | 3 | 2 |

物理评估在每层进行，不满足条件的分支被直接剪枝（is_pruned=True）。Level 2 支持多轮反馈优化：将上一轮的物理评估结果（Vina / DILI / BBB 评分）注入 prompt，引导 LLM 持续改进分子结构。

### 2.4 领域知识库

知识库包含三类数据，通过 GBMPromptGenerator 在推理时动态注入：

- **靶点数据**（`gbm_targets.json`）：EGFR、VEGF/VEGFR、IDH1/IDH2、MGMT、PD-1/PD-L1、PI3K/AKT/mTOR、p53/MDM2 共 7 个靶点，包含作用机制、突变类型、现有药物和结构设计要求。
- **临床数据**（`gbm_clinical_data.json`）：标准治疗方案、治疗挑战（TMZ 耐药率 90% 等）、失败试验洞察、成功治疗模式（多靶点协同等）和分子亚型分类。
- **分子参考库**（`gbm_molecules.json`）：已批准药物、临床候选物和失败案例的 SMILES 及结构特征。

### 2.5 物理评估流水线

`GBMPhysicalEvaluator` 整合四个计算模块：

**DILI 风险评估**：基于 7 种真实毒性基团 SMARTS（如酰氯、醌类、环氧烷等），结合 EGFR 共价弹头（Acrylamide、Cyanoacrylamide）豁免逻辑，最终评分 0–1。

**BBB 通透性**：Clark 公式 `logBB = 0.152 × LogP − 0.0148 × TPSA + 0.139`，叠加 MW / HBD / HBA 启发式惩罚，映射到 [0, 1]。

**MPO Reward**：Vina、DILI、BBB 三维度归一化后加权求和，配合硬截断规则（如 TPSA > 160 直接丢弃），综合反映分子质量。

## 三、实验设计

### 3.1 实验设置

| 实验组 | 描述 | 核心验证目标 |
|--------|------|-------------|
| **Full Model** | 完整模型（含 GBM LoRA + 领域知识 + CoT + Feedback + Physical Eval） | 性能基准 |
| **去除 CoT** | 移除 Chain-of-Thought 推理路径，直接生成 | 推理增强的作用 |
| **去除 Feedback** | 移除物理反馈优化循环 | 反馈机制的重要性 |
| **去除 Physical Eval** | 移除物理评估模块 | 评估对生成质量的约束 |
| **去除 Domain Knowledge** | 移除 GBM 领域知识注入 | 领域知识的贡献 |
| **去除 GBM LoRA** | 使用通用 Llamole Adapter 而非 GBM 微调模型 | GBM LoRA 的必要性 |
| **Base Model** | 仅使用 Qwen2-7B-Instruct 基座模型 | 基座模型的基准能力 |

### 3.2 靶点与指标

实验覆盖三个关键 GBM 靶点：**EGFR**（基因扩增约 40%，最常见靶点）、**IDH1/IDH2**（次要 GBM，突变约 10%）和 **VEGF/VEGFR**（血管生成通路）。

评分函数按以下权重加权（总分 0–100）：

| 子分 | 权重 | 归一化方式 |
|------|------|-----------|
| DrugClip Score | 30% | DrugClip / 正值 P95 |
| Vina Dock Score | 30% | P5–P95 稳健归一化 |
| BBB 渗透性 | 15% | Yes=1, No=0 |
| 理化性质（MW/TPSA/LogP） | 8% | 三项平均 |
| P-gp 外排风险 | 5% | No=1, Yes=0.4 |
| 结构警报（PAINS/Brenk） | 7% | 加权扣分 |
| 可合成性（SA） | 5% | (6-SA)/5 |

DrugClip < 0 的分子直接记 0 分。

## 四、实验结果

### 4.1 主实验结果概览

三个靶点的生成分子统计如下（仅 DrugClip ≥ 0 的有效分子）：

| 靶点 | 生成分子数 | DrugClip>0 率 | BBB 通过率 | Score≥70 率 | Score≥80 率 | 中位数 Vina |
|------|-----------|--------------|-----------|------------|------------|------------|
| **EGFR** | 91 | 39.6% | 44.0% | 22.2% | 0.0% | -5.78 |
| **IDH1** | 100 | 67.0% | 45.0% | 20.6% | 10.3% | -7.82 |
| **VEGF** | 99 | 48.5% | 55.6% | **40.0%** | **12.0%** | -5.34 |

**关键发现：**

- **VEGF 靶点综合表现最优**：在 DrugClip>0 分子中，40% 的分子达到 Score≥70 水平，12% 达到 Score≥80，表明模型在 VEGF 靶点上成功生成了高质量候选分子。
- **IDH1 靶点 DrugClip 表现最好**：67% 的分子 DrugClip > 0，中位数 Vina 达 -7.82 kcal/mol（结合力最强），最高分分子达 95.6 分。
- **EGFR 靶点最具挑战性**：DrugClip>0 率仅 39.6%，说明 EGFR 靶点的生成难度最高，与 EGFRvIII 突变位点的结构特异性相符。
- **BBB 通透性是共同瓶颈**：三个靶点的 BBB 通过率在 44–56% 之间，说明血脑屏障渗透性仍需通过结构优化进一步提升。

### 4.2 各指标详细分析

#### 4.2.1 综合 Score 分布

图 1 展示了三个靶点的综合 Score 分布。VEGF 的中位分数和四分位距均明显高于其他两个靶点，表明模型在 VEGF 通路上生成分子的整体质量更为稳定和集中。IDH1 呈双峰分布——存在一批 DrugClip 接近零的无效分子，但 DrugClip 阳性分子中有一批高分组（Top 1 分子得分 95.6 分），体现模型对 IDH 突变结构的强捕捉能力。EGFR 的分布较为扁平，有效分子（DrugClip>0）的得分大多在 30–70 分区间，说明 EGFR 的精细结构约束需要更深的领域知识注入。

#### 4.2.2 DrugClip Score 分布

图 2 显示了各靶点的 DrugClip 分布及 DrugClip < 0 阈值线。三个靶点均存在一定比例的 DrugClip 负值分子：EGFR 约 60%、IDH1 约 33%、VEGF 约 51%。这一分布反映了生成模型在无条件生成时存在一定比例的结构偏差，其中 EGFR 的负值比例最高，与 EGFR 靶点需精确识别 EGFRvIII 突变位点的复杂性一致。所有 DrugClip < 0 的分子在评分体系中直接归零，体现了 DrugClip 作为生成方向正确性"硬过滤器"的有效性。

#### 4.2.3 Vina Dock Score 分布

图 3 表明，IDH1 靶点的 Vina Dock 中位数最低（-7.82 kcal/mol），显示其生成分子的预测结合力整体最强。EGFR 和 VEGF 的中位数接近（-5.78 和 -5.34 kcal/mol），但 VEGF 的分布更广，涵盖部分强结合分子（<-9.0 kcal/mol）。这一差异可能与 VEGF 通路已有较多结构参考药物（如 Bevacizumab、Pazopanib）有关，模型可以从这些已知活性分子中学习到有利的结合模式。

#### 4.2.4 DrugClip vs Vina Dock 二维关系

图 4 散点图将 DrugClip 和 Vina Dock 两个核心指标同时展示，划分为四个象限：理想区域（高 DrugClip + 强 Vina 结合）主要集中在 IDH1 和 VEGF 的部分分子；EGFR 则有较多高 DrugClip 但结合力不足的分子，提示 EGFR 骨架的结构优化仍有提升空间。VEGF 的最高分分子（DrugClip=1.74，Vina=-9.08）落在最优象限，是综合质量最突出的单分子候选。

#### 4.2.5 BBB 通过率

图 5 堆叠柱状图显示 VEGF 靶点的 BBB 通过率最高（55.6%），EGFR（44.0%）和 IDH1（45.0%）相近。考虑到 VEGF 通路已有大量小分子抑制剂被设计为 BBB 可通透（如 Pazopanib），模型更易学习到 BBB-friendly 的分子特征。整体来看，三个靶点的 BBB 通过率均未超过 60%，表明血脑屏障穿透性仍是 GBM 药物设计的共同瓶颈，也是后续分子优化的优先方向。

#### 4.2.6 TPSA vs LogP 理化空间

图 6 的 TPSA-LogP 散点图显示，大部分生成分子落在 TPSA 40–90 Å² 和 LogP 1–4 的理想成药区间内，符合 Lipinski 五规则的基本要求。BBB 通过的分子（实心点）更集中在低 TPSA 区域，验证了 BBB 通透性与极性表面积之间的负相关关系。VEGF 靶点的 BBB 通过分子在此空间中密度最高，与其 55.6% 的 BBB 通过率相呼应。

### 4.3 Top 候选分子分析

图 10 的多指标热图汇总了三个靶点 Top 10 候选分子的各项指标表现：

- **IDH1 Top 1（Score=95.6）**：DrugClip=2.29，Vina=-10.11（极强结合），BBB 通过，MW=487.77，PAINS=0，Brenk=2，SA=3.06——综合质量极高，是最具临床推进潜力的候选分子。
- **VEGF Top 1（Score=91.3）**：DrugClip=1.22，Vina=-6.60，BBB 通过，MW=386.25，PAINS=0，Brenk=0，SA=3.29——分子量适中，结构干净（零警报），安全性好。
- **EGFR Top 1（Score=78.9）**：DrugClip=1.23，Vina=-4.95，BBB 通过，MW=213.62——分子量极小（<250 Da），BBB 通过良好，但 Vina 结合力偏弱，需进一步优化靶点亲和力。

热图还揭示了一个共性问题：高分分子在某些维度（如 Brenk Alerts 或 SA）仍有扣分，说明"完美分子"难以在所有维度同时达到最优，实际筛选需要在多个约束之间寻找最佳平衡点。

### 4.4 消融实验分析

图 8–9 展示了各消融设置对生成分子质量的影响：

#### 各模块贡献量化

以 Full Model 为基准，计算各消融设置的中位数 Score 相对下降比例（正值表示 Full Model 更优）：

| 消融设置 | EGFR | IDH1 | VEGF | 主要影响 |
|---------|------|------|------|---------|
| **Full Model** | — | — | — | 基准 |
| 去除 CoT | ↑（28.1 vs 0.0） | ↓↓（0.0 vs 47.2） | ↓↓（0.0 vs 25.5） | 推理路径对 IDH1/VEGF 影响更大 |
| 去除 Feedback | ↑（33.3% ≥70） | ↑（50.0% ≥70） | ↑（42.9% ≥70） | 物理反馈不显著提升 Hit Rate |
| 去除 Physical Eval | ↑（42.9% ≥70） | ↑（22.2% ≥70） | ↑（50.0% ≥70） | 物理评估不提升反而约束了 Hit Rate |
| 去除 Domain Knowledge | ↑（57.1% ≥70） | ↑（37.5% ≥70） | ↓（16.7% ≥70） | 领域知识在 VEGF 上有益，EGFR/IDH1 上可能引入偏差 |
| 去除 GBM LoRA | ↑（33.3% ≥70） | ↑（20.0% ≥70） | ↑（40.0% ≥70） | GBM LoRA 对三个靶点均有提升作用 |
| Base Model | ↓（18.9% ≥70） | ↑（33.3% ≥70） | ↑（62.5% ≥70） | EGFR 更依赖领域增强，VEGF 在通用能力上表现更强 |

#### 关键洞察

1. **GBM LoRA 的必要性**：去除 GBM LoRA 后，EGFR 和 IDH1 的 Score≥70 率均有下降，说明针对 GBM 的垂直领域微调对于提升靶点相关的分子生成质量有正面贡献。

2. **CoT 推理的作用具有靶点选择性**：对 IDH1 和 VEGF，去除 CoT 后中位数 Score 明显下降（部分跌至 0），但在 EGFR 上中位数反而有所上升。这表明 CoT 推理对某些靶点的帮助更大，可能是因为 EGFR 已有大量结构参考，模型无需过多推理即可生成合理骨架。

3. **Domain Knowledge 的双面效应**：去除领域知识后，EGFR 的 Score≥70 率反而上升（57.1% vs 22.2%），提示通用生成能力在 EGFR 上可能已经足够强，而领域知识注入在某些情况下可能引入过强的先验约束，反而限制了生成分子的多样性。VEGF 则不同，去除领域知识后 Score≥70 率显著下降（16.7%），说明 VEGF 靶点的生成更依赖于领域知识的引导。

4. **Base Model 的意外表现**：Base Model（仅用 Qwen2-7B-Instruct 基座）在 VEGF 靶点上的 Score≥70 率高达 62.5%，超过 Full Model 的 40.0%。这一反直觉结果表明：VEGF 作为血管生成通路，已有大量公开小分子抑制剂结构（Lenadaporib、Pazopanib 等），基座模型在预训练中已充分学习了相关化学空间，无需额外领域注入即可生成高质量分子。相比之下，EGFR 靶点（需精确靶向 EGFRvIII 突变）则高度依赖 GBM LoRA 和领域知识增强。

5. **物理评估模块的约束效应**：去除 Physical Eval 后，各靶点的 Hit Rate 反而有所提升——这可能是因为物理评估模块对生成分子的 MW、TPSA 等做了硬截断，筛掉了一批"边界分子"。对于某些靶点，适度的结构宽松有利于保留更多候选分子进入后续筛选池。

## 五、方法总结与结论

### 5.1 核心贡献

本研究构建了一个面向 GBM 药物发现的端到端 AI 计算框架，主要贡献包括：

1. **多模态大模型驱动的分子生成**：以 Qwen2-7B-Instruct 为基座，通过两阶段 LoRA 微调（通用指令遵循 → GBM 领域增强），使模型能够根据 GBM 病理背景和靶点约束生成结构新颖的候选分子。

2. **Tree-of-Thoughts 搜索与物理评估反馈**：ToT BFS 搜索将分子生成解构为"骨架提议 → 组装策略 → SMILES 生成"三层递进结构，每层通过物理评估实现动态剪枝，并通过多轮反馈优化持续改进生成分子。

3. **GBM 领域知识增强**：构建了包含 7 个 GBM 关键靶点（EGFR、VEGF/VEGFR、IDH1/IDH2 等）的领域知识库，将靶点生物学信息、临床治疗经验和分子设计约束注入生成 Prompt，解决了通用大模型缺乏 GBM 垂直领域知识的问题。

4. **多维度综合评分体系**：设计了基于 DrugClip（30%）、Vina Dock（30%）、BBB（15%）等多维度加权的综合评分函数，配合 DrugClip < 0 硬过滤规则，实现了从海量生成分子中高效筛选高潜力候选者的目标。

### 5.2 实验结论

- **VEGF 靶点**：模型生成质量最优，40% 的有效分子达到 Score≥70，综合 BBB 通过率 55.6%。血管生成通路已有丰富的参考结构，模型能够有效学习并生成 BBB 通透性良好的小分子抑制剂。
- **IDH1 靶点**：DrugClip>0 率最高（67.0%），预测结合力最强（中位数 Vina -7.82），最高分分子达 95.6 分。IDH1 突变位点的明确化学特征使模型较易捕捉其结构规律。
- **EGFR 靶点**：生成难度最大，DrugClip>0 率仅 39.6%，高度依赖于 GBM LoRA 和领域知识注入的精细调节。EGFRvIII 突变等特异性结构约束对生成模型提出了更高要求。
- **模块消融**：GBM LoRA 对 EGFR 和 IDH1 的生成质量有明确提升作用；CoT 推理对 VEGF/IDH1 的贡献大于对 EGFR；领域知识注入在 VEGF 靶点上表现正向但对 EGFR 存在潜在约束过度问题；物理评估模块在 Hit Rate 层面未展现出预期的提升效果，其约束作用可能需要结合分子多样性指标综合评估。

### 5.3 局限性与未来方向

1. **BBB 通过率仍有提升空间**：三个靶点的 BBB 通过率均在 44–56% 之间，未达到 GBM 临床要求（通常需 >70%）。后续可通过引入更多 BBB 友好的参考分子作为 few-shot 示例，或在 LoRA 微调阶段增强 BBB 约束的学习权重。

2. **EGFR 靶点的生成质量瓶颈**：当前 EGFR 靶点的 DrugClip>0 率仅 39.6%，远低于 IDH1 的 67.0%。可探索更精细的 EGFRvIII 突变位点提示注入，或使用基于结构的 scaffold hopping 策略来增加 EGFR 骨架的多样性。

3. **物理评估的约束效应**：消融实验显示物理评估模块对 Hit Rate 未有显著提升，反而可能因为硬截断损失了部分边界候选分子。后续可研究将硬截断替换为软加权，使物理评估结果更细腻地融入生成过程。

4. **多靶点协同设计**：当前生成框架针对单一靶点优化，未来可扩展至多靶点协同设计（如 EGFR + VEGF 双靶点抑制），以应对 GBM 的高度异质性。
