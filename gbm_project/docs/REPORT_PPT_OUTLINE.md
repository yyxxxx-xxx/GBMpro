## 第 3 页 —— 方法: 三层架构与双 LoRA 设计

**标题**: RL 以独立 LoRA 叠加在 SFT 模型之上, 完整保留原有化学知识

**配图** (核心架构图, 这页的图是全场最重要的一张):
```
┌─────────────────────────────────────────────┐
│  Qwen2-7B-Instruct  (冻结)                  │
│  ├─ Llamole LoRA r=8  (冻结, 通用分子能力)   │
│  └─ GBM SFT LoRA r=16 (冻结 = prior/CLIP锚点)│
├─────────────────────────────────────────────┤
│  RL LoRA r=16  (可训练 = agent)              │  ← 本工作的增量
└─────────────────────────────────────────────┘
        ↓ rollout: prompt → SMILES × G=16
        ↓ Vina 对接 + admet-ai 打分 → reward
        ↓ 组内 z-score → advantage → GRPO 更新
```

**要点**:
- **关键设计**: SFT LoRA 冻结, 它同时充当 **prior (KL 锚点)** 和 **CLIP 参照**
  - 这样 KL 的定义是干净的: `KL(agent ‖ prior)`, 而 prior 确实代表"训练好的化学模型"
  - RL LoRA 只改**策略**, 不改**知识**, 所以 30 步就能见效而不会灾难性遗忘
- 一句话: "SFT 模型是我们原来的模型, RL 是它之上的第三个 adapter"

> 💡 这页要讲透"为什么用三 adapter 而不是直接微调 SFT LoRA"——审稿人会问这个。

## 第 4 页 —— 奖励函数设计

**标题**: 加权几何平均的 MPO 奖励, 硬约束 + 软惩罚双层结构

**配图** (公式居中 + 右侧小表):
```
Reward = ∏ᵢ sᵢ^wᵢ        (加权几何平均, REINVENT4 风格)

s = [Vina, DILI, hERG, BBB, TPSA, MW, PGP, AMES, QED]

其中: 硬约束违反 → prune (不进入 advantage)
      端点越界   → floor 惩罚 (不用 0 硬归零)
```

右侧小表放 **三种聚合方式的实测对比** (这是我们的一个关键实验决策):
| 聚合方式 | ρ(reward, pIC50) | 稳定性(DILI ±0.1 最坏相对影响) |
|---|---|---|
| geometric | +0.281 | **14.0%** ← 采用 |
| arithmetic | +0.101 | 4.6% |
| harmonic | +0.320 | 70.3% ← 判别力高但极不稳定 |

**要点**:
- 为什么不用算术平均: 端点归零会把整个 reward 拉成 0, 毒化统计
- 为什么不用调和平均: 判别力只高一点, 但单端点 0.1 抖动引起 70% reward 变化 → **LLM 收到的是噪声而非梯度**
- 硬截断阈值是**实测得出**的, 不是拍的

> 💡 强调"稳定性"这一列: 对 LLM 反馈循环来说, **信号抖动比判别力更重要**。

## 第 6 页 —— 机制证据: 违规率下降 (★ 全篇核心之二)

**标题**: 违规率与截断率同时下降, 排除 reward hacking

**配图**: 两个并列的对比条形图 (或一个带双箭头的坡度图):
```
                base    RL     变化
结构守卫违规    39      33     -15.4%  ↑
硬约束截断      71      55     -22.5%  ↑
```

**要点**:
- **这是最有力的反 hacking 论据**: 如果 RL 在"骗分", 最常见的路径就是
  ① 生成结构守卫拦不住的畸形分子 ② 触碰硬约束边界
  实测两者**都降了**
- 补充一句 8 维度的方向性论证:
  - BBB +12.3% (↑ 好) —— 而 SFT 数据本身**偏向低 BBB** (偏置检查 t=-9.07)
  - hERG -17.1% (↓ 好), PGP -25.5% (↓ 好), AMES -11.2% (↓ 好)
  - **RL 的改善方向与数据偏置相反** → 说明它学的是 reward 指定的物理, 不是数据捷径

> 💡 这是本汇报**最有说服力的一页**, 一定要讲透"数据偏置方向相反"这个反证。

## 第 7 页 —— 消融实验: 定位最优超参 (★ 全篇核心之三)

**标题**: 4 组消融定位 β_kl=0.08 为最优, 多样性过滤对分布外推有实际贡献

**配图**: 直接复用 **`experiments/m4_ablation.png`** (已存在, 3 面板: 收敛曲线 / KL 漂移 / 斜率对比)

**配图补充**: 右侧或下方放一张 4 行汇总表:
| 实验 | 配置 | reward 中位数 | 逐 prompt 胜率 | MW p | 结论 |
|---|---|---|---|---|---|
| **M4-A** | β_kl=0.08, 80 步 | **+52.1%** | **8/8** | 0.0144 | ✅ 最优 |
| M4-B | β_kl=0.15 | -9.5% | 4/8 | 0.5542 | ❌ 过度约束, 负斜率 |
| M4-C | β_kl=0.08, 去掉多样性过滤 | +44.7% | 7/8 | 0.2595 | ⚠️ 分布更散, 显著性弱化 |
| M4-D | G=8, lr=5e-6 | +37.0% | 8/8 | 0.0312 | ⚠️ 收敛偏慢 |

**要点**:
- **β_kl 是最敏感的超参**, 且存在明确的最优值:
  - β_kl=0.02 → 输出长度崩塌 (~60-90 tokens vs ~200), KL 飙升到 0.345 → 策略塌缩
  - β_kl=0.08 → 平衡
  - β_kl=0.15 → 过度约束, reward 出现**负斜率**
- **M4-C 说明多样性过滤确实有贡献, 但机制比"防 prompt starvation"温和**:
  - 去掉过滤后中位数从 +52.1% 降到 +44.7%, Mann-Whitney p 从 0.0021 弱化到 0.2595
  - 即: 过滤的主要价值是**让提升更稳定、更显著**, 而不是避免某几个 prompt 霸占配额
  - ⚠️ 汇报时**不要**说成"去掉过滤就崩了" —— 实际是"变弱但没崩"

> 💡 这页的诚实之处: M4-C 没有戏剧性失败, 但它量化了多样性过滤的**边际价值**
> (中位数 +7.4pp, 显著性 p 从 0.26 → 0.002), 这本身是个有用结论。

## 第 8 页 —— 数据质量与偏置审查 (PBCNet2.0 借鉴)

**标题**: 主动披露 SFT 数据的统计偏置, 证明 RL 提升不是数据捷径

**配图**: 热力图或分组条形图, 展示偏置检查结果:

| 性质 | Δ均值 | t | 判定 |
|---|---|---|---|
| MW / QED / DILI_prob | ≈0 | <1.2 | ✅ 无偏 |
| **TPSA** | +3.12 | +8.27 | ⚠️ 偏高的极性改造 |
| **BBB_prob** | -0.030 | -9.07 | ⚠️ 偏低的 BBB 改造 |
| hERG_prob / AMES_prob | +0.011 / -0.011 | +3.71 / -3.75 | ⚠️ 弱偏 |

**要点**:
- 方法: 对**共享 Murcko 骨架**的分子对 (只改 R-group) 做 Δ 统计, 检验均值是否偏离 0
- **关键技术细节 (值得强调)**: 配对方向必须**外生** (用 SMILES 字典序), 否则:
  - 按数据原始顺序 → t=-12.3, 造出假偏置
  - 对称化取 → t=0, 检验失效
- 结论: 数据确实有偏置 (TPSA/BBB), **但 RL 在 BBB 维度的改善方向与偏置相反** → RL 确实在对抗偏置

> 💡 这页的价值: **主动暴露自己的数据弱点, 并给出反驳证据**。这比藏着更能赢得信任。

## 第 9 页 —— 方法改进: 成对差分 Advantage (PBCNet2.0 启发)

**标题**: 引入 PBCNet2.0 的成对差分思想, 缓解 reward 左尾稀释问题

**配图**: 左右对比示意 (不需要真图, PPT 里画两个小示意图即可):
```
z-score:   A_i = (R_i - mean)/std          ← 隐含"绝对分数高=更好"
pairwise:  A_i = (R_i - mean)/(R_max-R_min) ← 只看组内相对差
```

**配图补充**: 四种模式的离线对比表 (用 M3 真实评估数据算的, 已有):
| 模式 | \|adv\|均值 | 跨度均值 | 组间尺度CV |
|---|---|---|---|
| zscore | 0.9130 | 2.6096 | 0.055 |
| pairwise | 0.3537 | 1.0000 | 0.000 ← 抹平组间差异 |
| **pairwise_scaled** | 0.3634 | 1.0231 | **0.062** ← 推荐 |
| rank | 0.4295 | 1.6562 | 0.153 |

**要点**:
- 依据: PBCNet2.0 的 readout 只做 `emb1 - emb2`, 论文指出拼接会让模型退化为"记忆配体结构"
- 映射: 我们的 reward 里混着大量**与组内对比无关**的常数偏移 (TPSA 归一化、MW 分段、ADMET 地板), 会稀释真实相对差异
- **发现并修正了纯 pairwise 的缺陷**: 纯 pairwise 把所有组拉到同一尺度, 抹平了"信息量差异" → 我们提了 `pairwise_scaled` 折中
- **兼容性保证**: 默认仍是 zscore, 行为**逐位不变**, 历史实验完全可复现 (28/28 单元测试通过)

> 💡 如果时间紧, 这页可以只讲"我们借鉴了一个新方法并做了改进", 不必展开细节。

### 容易出错的地方 (写 PPT 时避开)

1. ❌ 不要把 M4-A 说成"和 M3 一样" —— M4-A 是 80 步, M3 是 30 步, M3 才是最优 checkpoint
2. ❌ 不要混用 "reward 提升 52%" 和 "Vina 提升 4.6%" —— 前者中位数, 后者均值, 口径不同
3. ❌ 不要说 "8 个 prompt 全部提升" —— M3 是 7/8 (M4-A/M4-D 才是 8/8)
4. ❌ 不要说 M4-C "崩了" —— 实际是"变弱但没崩": 7/8 胜率, p=0.0207 (跨 prompt t), MW p=0.2595
   ❌ 更不要引用 "3/8, p=1.000" —— 那是错误口径的产物, 逐分子配对会全为 0 差值
5. ❌ 不要说"数据没有偏置" —— 实际 TPSA/BBB 有显著偏置, 要说"有偏置但 RL 方向与之相反"
6. ✅ 正确说法: "reward 中位数提升 52.1%, 均值提升 31.1%, 中位数提升更强说明典型分子的真实改善更大"
7. ⚠️ 显著性一律用"逐 prompt 均值配对"口径, 见第 7 页附的表

## 演讲备注 (关键话术)

**第 2 页开场**:
> "我们的 SFT 模型已经能生成类药分子了。但它有一个根本限制——它不知道生成的分子到底好不好。我们想给它装上物理反馈。"

**第 5 页**:
> "中位数提升 52% 比均值提升 31% 更值得强调。均值会被左尾拉低, 中位数代表'典型分子'的真实改善。"

**第 6 页 (最重要)**:
> "各位可能会问: 你们的 reward 涨了, 会不会是模型在骗分? 我们查了两种最常见的作弊路径——生成畸形分子逃避结构守卫, 和卡在硬约束边界。结果这两种违规**都下降了 15% 和 22%**。更关键的是, 我们的 SFT 数据本身就偏向低 BBB 分子, 而 RL 把 BBB 提升了 12%——**方向和数据偏置是相反的**。"

**第 7 页**:
> "M4-C 量化了多样性过滤的边际价值: 去掉过滤后中位数从 52% 降到 45%, Mann-Whitney 的 p 从 0.002 弱化到 0.26。提升还在, 但**变得不那么显著**。所以过滤的价值是让提升更稳, 而不是避免某几个 prompt 霸占配额——我们一开始的假设是后者, 数据纠正了我们。"

**第 8 页**:
> "我们主动查了 SFT 数据有没有系统性偏置, 结论是**有**。但正因为我们查了并且公开了, 我们才能用'RL 的改善方向与数据偏置相反'来证明提升是真的。"

**第 11 页收尾**:
> "方法论和证据链在 IDH1 上已经闭合。现在需要 2 张卡, 3-4 小时, 把它在 EGFR 和 VEGFR 上复现一遍, 确认这是跨靶点的通用能力, 而不是 IDH1 的特例。"
