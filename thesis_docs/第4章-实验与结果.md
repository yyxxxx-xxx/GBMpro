### 4.2.4 评估指标

**（1）综合Score（TotalScore）**

综合Score是生成分子的核心评估指标，由多维度评估体系加权计算得到：

```
DrugClip_norm = max(DrugClip, 0) / 3.0  # 归一化到[0, 1]
综合Score = 0.30 × DrugClip_norm + 0.30 × vina_norm
          + 0.15 × bbb_norm + 0.08 × (1-dili_prob)
          + 0.07 × (1-pains_alert_score) + 0.05 × (1-herg_prob)
          + 0.05 × SA_score
# 最终归一化到[0, 100]
```

**（2）DrugClip Score**

DrugClip是一种基于对比学习的分子-靶点结合活性预测模型。DrugClip Score范围约为[-3, +3]，正值表示预测有活性，负值表示无活性。

**（3）Vina Dock Score**

AutoDock Vina对接分数（kcal/mol），越负表示结合越强：
- Vina < -7.0 kcal/mol：强结合
- -7.0 ≤ Vina < -5.0 kcal/mol：中等结合
- Vina ≥ -5.0 kcal/mol：弱结合（触发硬截断剪枝）

**（4）BBB穿透评分**

BBB评分（0-1），基于Clark公式结合启发式惩罚计算：
- BBB_score > 0.7：高CNS渗透性
- 0.4 ≤ BBB_score ≤ 0.7：中等CNS渗透性
- BBB_score < 0.4：低CNS渗透性

**（5）分层层级**

| 层级 | Score范围 | 含义 |
|------|-----------|------|
| 高优先级 | Score ≥ 80 | 综合指标优秀，建议优先验证 |
| 建议验证 | 70 ≤ Score < 80 | 综合指标良好，值得进一步研究 |
| 保留观察 | 60 ≤ Score < 70 | 基本达标，需进一步优化 |
| 优先淘汰 | Score < 60 | 多项指标未达标 |

### 4.3.4 DrugClip与Vina相关性分析

> **【图表4：DrugClip vs Vina散点图】**
> 图表来源：gbm_project/figures/zh/fig4_drugclip_vs_vina.zh.png

**图表描述**：图4.4以DrugClip Score为x轴、Vina对接分数为y轴绘制了DrugClip>0分子的2D散点图。水平虚线为Vina=-7.0参考线。

**结果描述**：
- 大部分有效分子落在图的**左上方区域**（高DrugClip+强Vina），说明模型能够生成具有预测活性和物理结合亲和力的分子
- DrugClip与Vina之间存在**弱负相关**，DrugClip分数越高，点越倾向于往更负（更优）的Vina区段聚集
- **IDH1橙色点**在"高DrugClip+强结合"区域最为集中，说明IDH1是当前体系最成熟、收益最高的验证靶点
- EGFR靶点DrugClip均值相对较低（0.57），说明在EGFR靶点下"生成可解析分子"与"生成预测活性分子"存在一定差异

> **【图表11：Top分子质量分析】**
> 图表来源：gbm_project/figures/zh/fig9_ablation_relative_drop.zh.png

**图表描述**：图4.11以水平条形图展示了各对比方法Top-10%分子平均DrugClip得分的相对下降幅度。

- PlayMolecule AI生成的分子出现分数高于本文模型的情况，但是生成分子呈现明显的骨架收敛现象，尽管候选分子均为有效且非重复SMILES，但其Murcko scaffold高度一致，主要差异集中在末端取代基和芳环取代位点，说明模型倾向于围绕已知EGFR抑制剂样母核进行局部结构微调，化学空间探索范围相对有限

## 4.5 消融实验结果

### 4.5.1 消融实验设计

为量化各核心模块对生成质量的贡献，本文设计了6组消融实验：

| 实验编号 | 实验名称 | 消融内容 | 配置修改 |
|---------|---------|---------|---------|
| Ablation-1 | 无CoT推理 | 移除CoT推理模板，仅使用基础Prompt | `use_cot_reasoning: false` |
| Ablation-2 | 无物理反馈 | 移除物理引擎反馈，ToT搜索无反馈闭环 | `enable_physical_feedback: false` |
| Ablation-3 | 无物理评估 | 移除整个物理评估环节 | `evaluate_gbm_properties: false` |
| Ablation-4 | 无领域知识 | 移除GBM知识库注入 | `use_gbm_domain_knowledge: false` |
| Ablation-5 | 无GBM LoRA | 仅使用通用Llamole适配器，不加载GBM LoRA | `adapter_name_or_path: saves/Llamole-Qwen2-7B-Instruct-Adapter` |
| Ablation-6 | 基线模型 | 不使用任何适配器，直接用Qwen2-7B-Instruct | `adapter_name_or_path: null` |

|---------|------|------|------|-----------|
| **Full Model** | 44.0% | 45.0% | 55.6% | **47.8%** |
| No CoT&ToT | 45.5% | 38.7% | 50.0% | 44.2% |
| w/o ToT (CoT only) | 34.5% | 35.9% | 51.4% | 39.8% |
| w/o Feedback | 83.3% | 61.1% | 80.0% | 73.1% |
| w/o Physical Eval | 52.2% | 52.9% | 55.6% | 53.5% |
| w/o Domain Knowledge | 73.3% | 52.6% | 66.7% | 62.8% |
| w/o GBM LoRA | 53.8% | 40.0% | 52.9% | 48.3% |
| Base Model | 51.9% | 62.5% | 88.9% | 60.8% |

> **关键发现**：去除领域知识和去除反馈后，BBB通过率反而**大幅上升**（分别达到62.8%和73.1%），但这恰恰说明这两个模块在提升DrugClip和Vina得分的同时，也对分子理化性质施加了更严格的约束。BBB通过率高不等于综合质量好——需要结合DrugClip和Vina数据综合判断。

## 4.6 结果分析

### 4.6.1 领域知识注入的效果分析

1. **对DrugClip均值的贡献**：去除领域知识后，三靶点DrugClip均值从0.74下降至0.67（下降9.5%）。值得注意的是，去除领域知识后EGFR的DrugClip均值反而从0.57上升至0.60，说明领域知识对DrugClip得分的贡献存在靶点特异性。

2. **对Vina结合能力的贡献**：去除领域知识后，EGFR的Vina均值从-5.78变为-6.12 kcal/mol（略有改善），VEGF从-5.34变为-5.16 kcal/mol（略微退化）。整体来看，领域知识对物理结合能力的贡献不如对DrugClip的贡献显著。

3. **对不同靶点的差异化影响**：IDH1对领域知识移除较敏感（DrugClip均值下降16.1%），而VEGF几乎无变化（0.0%），EGFR反而略微上升。

### 4.6.2 CoT-ToT推理策略的效果分析

1. **CoT推理的作用**：去除CoT推理后，DrugClip均值从0.74下降至0.55（**下降25.7%**），说明CoT推理通过7个结构化步骤引导模型逐步推理，有效提升了生成分子的DrugClip活性预测得分。

2. **ToT反馈闭环的作用**：去除物理反馈后，DrugClip均值从0.74下降至0.59（**下降20.3%**），VEGF的DrugClip均值从0.62大幅下降至0.55（下降11.3%）。

3. **CoT与ToT的协同效应**：CoT更多影响"生成什么结构"，ToT反馈更多影响"生成的结构是否满足物理约束"。两者协同才能实现从"能生成"到"能生成高质量DrugClip活性"的跨越。

### 4.6.3 物理评估体系的必要性分析

1. **去除物理评估后的严重退化**：去除物理评估后，DrugClip均值从0.74大幅下降至0.50（**下降32.4%，为最大降幅**）。Vina均值在三个靶点上均出现退化，说明无物理评估时生成分子的质量严重下降。

2. **对不同靶点的差异化影响**：IDH1对物理评估移除最敏感（DrugClip均值下降49.5%），说明该靶点下的生成分子质量最依赖物理评估的筛选和引导。

3. **Delta Scoring机制**：允许毒性增量≤0.05的分子暂不触发硬剪枝，为探索保留机会。这一设计在保持安全性底线的同时，扩展了分子生成的化学空间。

### 4.6.4 GBM LoRA微调的效果分析

1. **对DrugClip均值的贡献**：去除GBM LoRA后，DrugClip均值从0.74下降至0.66（下降10.8%）。

2. **对不同靶点的差异化影响**：EGFR对GBM LoRA移除较敏感（DrugClip均值下降13.2%），VEGF次之（下降4.8%）。

3. **验证LoRA微调的重要性**：GBM LoRA适配器的引入使DrugClip均值提升了约10.8%，说明针对GBM领域的LoRA微调对于模型生成高质量GBM候选分子具有重要作用。

## 4.7 本章小结

本章在EGFR、VEGF/VEGFR和IDH1/IDH2三个代表性GBM靶点上对本文提出的GBM候选分子生成框架进行了系统性的实验验证。主要结论如下：

**主实验结果**（DrugClip>0分子）：
- **IDH1表现最佳**：DrugClip均值0.93（最高），Vina均值-7.82 kcal/mol（唯一跨越-7.0强结合线）
- **VEGF BBB优势明显**：BBB通过率55.6%（最高），有利于CNS药物设计
- **三靶点综合**：DrugClip均值0.74，Vina均值-6.31 kcal/mol，BBB通过率47.8%

**对比实验结果**：
- LlamaMol模型DrugClip>0分子占比（55%）显著高于LlaSMol-Mistral-7B（39%）和Top-K（38%）
- LlamaMol在Top-10%高质量分子层面全面优于对比方法，IDH1靶点达81.71分，VEGF靶点达79.21分
- PlayMolecule AI存在骨架收敛问题，Molecule-oriented LLaMA和Llamole Qwen直接靶点生成分子能力弱

**消融实验量化贡献**（DrugClip均值下降%）：
| 消融设置 | 三靶点下降% | 关键发现 |
|---------|-----------|---------|
| w/o Physical Eval | **32.4%** | 影响最大 |
| w/o ToT (CoT only) | **25.7%** | 推理引导显著有效 |
| No CoT&ToT | **24.3%** | 反馈闭环不可或缺 |
| w/o Feedback | **20.3%** | 反馈对VEGF影响大 |
| w/o GBM LoRA | 10.8% | LoRA微调有正向贡献 |
| w/o Domain Knowledge | 9.5% | 领域知识有贡献但相对较小 |
| Base Model | **45.9%** | 领域适配至关重要 |

这些结果表明，本文提出的多模块协同框架能够有效地整合领域知识、推理能力和物理验证，从而生成具有良好成药性潜力的GBM候选分子。
