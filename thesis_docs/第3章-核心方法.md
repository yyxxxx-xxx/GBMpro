## 3.2 GBM靶点知识库构建

### 3.2.1 知识库架构设计

GBM靶点知识库是整个生成系统的核心数据基础，负责管理与GBM药物研发相关的多维度专业知识。知识库采用模块化设计，包含以下四个核心子库：

**（1）GBM靶点信息库**（`gbm_targets/gbm_targets.json`）

该子库存放7个关键GBM治疗靶点的详细信息。每个靶点条目包含以下字段：

| 字段名 | 数据类型 | 描述 |
|--------|----------|------|
| `name` | string | 靶点名称（如"EGFR"、"VEGF/VEGFR"） |
| `description` | string | 靶点的生物学功能与在GBM中的作用机制描述 |
| `mutation_types` | list[string] | 与GBM相关的突变类型列表 |
| `current_drugs` | list[string] | 针对该靶点的已上市或在研药物 |
| `challenges` | list[string] | 针对该靶点进行药物开发面临的主要挑战 |
| `structural_requirements` | dict | 分子结构设计要求（MW、LogP、BBB通透性、选择性等） |

**7个核心靶点的详细信息**：

> **EGFR（表皮生长因子受体）**
> - 描述：GBM中最常见的基因扩增类型（约40%），导致肿瘤细胞过度增殖
> - 突变类型：EGFRvIII（外显子2-7缺失）、EGFR扩增、EGFR点突变
> - 当前药物：Erlotinib、Gefitinib、Afatinib
> - 核心挑战：耐药性、血脑屏障穿透、野生型EGFR毒性
> - 结构要求：MW < 500，LogP 2-4，BBB通透性高，选择性EGFRvIII > WT-EGFR 10倍以上

> **VEGF/VEGFR（血管内皮生长因子通路）**
> - 描述：GBM血管生成的关键驱动因子
> - 突变类型：VEGF过表达、VEGFR扩增
> - 当前药物：Bevacizumab（贝伐珠单抗）、Cediranib、Pazopanib
> - 核心挑战：血管规范化悖论、复杂耐药机制、需要联合治疗
> - 结构要求：MW < 600，LogP 1-3，BBB通透性中等

> **IDH1/IDH2（异柠檬酸脱氢酶）**
> - 描述：主要在继发性GBM中出现（约10%），预后相对较好
> - 突变类型：IDH1 R132H、IDH2 R172K
> - 当前药物：Ivosidenib、Enasidenib
> - 核心挑战：突变异质性、下游代谢物积累、免疫调节效应
> - 结构要求：MW < 500，LogP 2-4，BBB通透性高

> **MGMT（O6-甲基鸟嘌呤-DNA甲基转移酶）**
> - 描述：GBM化疗耐药的关键因子，MGMT启动子甲基化状态决定替莫唑胺敏感性
> - 突变类型：MGMT启动子甲基化、MGMT表达水平
> - 当前药物：Temozolomide（替莫唑胺）
> - 核心挑战：耐药性发展、MGMT修复机制、替代DNA损伤通路
> - 结构要求：MW < 400，LogP 1-3，BBB通透性高，具有DNA损伤选择性

> **PD-1/PD-L1（免疫检查点通路）**
> - 描述：GBM免疫微环境的关键调节因子
> - 表达模式：肿瘤细胞、免疫细胞、微环境
> - 当前药物：Pembrolizumab（帕博利珠单抗）、Nivolumab（纳武利尤单抗）
> - 核心挑战：免疫抑制微环境、BBB限制、联合免疫治疗
> - 结构要求：MW < 800（抗体类）/< 600（小分子类），LogP 1-4，BBB通透性中-高

> **PI3K/AKT/mTOR（PI3K信号通路）**
> - 描述：GBM中激活最频繁的信号通路（约80%）
> - 突变类型：PTEN缺失、PIK3CA突变、AKT扩增
> - 当前药物：Everolimus（依维莫司）、Temsirolimus（替西罗莫司）
> - 核心挑战：反馈激活、通路冗余、毒性管理
> - 结构要求：MW < 600，LogP 2-4，BBB通透性高，PI3K选择性高

> **p53/MDM2（p53通路）**
> - 描述：TP53突变率约30%，MDM2扩增约10%
> - 突变类型：TP53突变、MDM2扩增、MDM4扩增
> - 当前药物：无特异性药物
> - 核心挑战：p53通路复杂性、获得性耐药、野生型p53毒性
> - 结构要求：MW < 550，LogP 2-4，BBB通透性高，MDM2选择性高

**（2）GBM临床治疗数据库**（`gbm_clinical/gbm_clinical_data.json`）

该子库存放GBM临床治疗的最新进展与经验教训，包含：
- 标准治疗方案（Stupp方案：手术+放疗+替莫唑胺）
- 临床试验洞察（成功与失败案例分析）
- 分子亚型分类（Proneural、Neural、Classical、Mesenchymal）
- 生物标志物（IDH突变、1p/19q共缺失、MGMT启动子甲基化）
- 耐药机制（替莫唑胺耐药、免疫逃逸、血管生成）

**（3）GBM分子参考数据库**（`gbm_molecules/gbm_molecules.json`）

该子库存放已获批药物和临床试验分子的结构与活性信息：

| 分类 | 代表药物/化合物 | 关键特征 |
|------|----------------|----------|
| 已批准药物 | Temozolomide | 烷化剂，MW 194，LogP -0.67，口服给药 |
| 已批准药物 | Bevacizumab | 抗VEGF单克隆抗体，MW ~149,000，静脉给药 |
| 已批准药物 | Everolimus | mTOR抑制剂，MW 958，LogP 3.1，BBB通透性中等 |
| 临床候选 | ABT-414 | EGFR抗体药物偶联物（ADC），靶向EGFRvIII |
| 临床候选 | GDC-0084 | PI3K/mTOR双靶点抑制剂，MW 381，脑渗透性良好 |
| 临床候选 | PTK-787 | VEGFR抑制剂，MW 481，LogP 2.8 |
| 结构母核 | 嘧啶环 | 激酶抑制剂的常见母核 |

**（4）结构知识库**（`structural_knowledge_injector.py`）

该子库提供分子结构设计的专业知识注入，包含：
- 血脑屏障穿透的结构修饰策略（引入氟原子、甲氧基、氮原子）
- PAINS和Brenk警告结构过滤规则
- 常见活性药效团识别
- 合成可及性评估

### 3.2.2 知识库核心数据类

知识库基于以下数据类进行组织：

```python

class GBMTarget:
    """GBM靶点数据类"""
```

## 3.3 专用Prompt生成器设计

### 3.3.1 Prompt模板体系

专用Prompt生成器（`gbm_prompt_generator.py`）基于YAML配置文件构建多层次、多策略的Prompt模板体系。核心模板包括：

**（1）基础GBM Prompt模板**

基础模板定义了GBM分子设计的通用要求框架：

```
[BASE_GBM_PROMPT]
请作为专业的GBM药物化学家，设计针对胶质母细胞瘤（GBM）的新型候选药物分子。
{specific_requirements}

设计原则：
1. 优先考虑血脑屏障（BBB）穿透性
2. 确保对GBM细胞的选择性毒性
3. 克服多药耐药机制
4. 良好的类药性（drug-likeness）
```

**（2）靶点特异性Prompt模板**

针对每个靶点，生成器根据知识库中的靶点信息动态构建靶点特异性Prompt：

```python
def _generate_target_specific_prompt(self, target: GBMTarget) -> str:
    """生成靶点特异性Prompt"""
    prompt = f"针对{target.name}通路设计GBM候选药物：\n\n"
    prompt += f"作用机制：\n{target.description}\n\n"
    prompt += f"突变类型：\n" + "\n".join(f"- {mut}" for mut in target.mutation_types) + "\n\n"
    prompt += f"现有药物：\n" + "\n".join(f"- {drug}" for drug in target.current_drugs) + "\n\n"
    prompt += f"挑战：\n" + "\n".join(f"- {challenge}" for challenge in target.challenges) + "\n\n"

    if target.structural_requirements:
        prompt += "分子设计要求：\n"
        for key, value in target.structural_requirements.items():
            prompt += f"- {key}: {value}\n"

    return prompt
```

### 3.3.2 CoT推理Prompt设计

Chain-of-Thought（思维链）推理Prompt引导模型进行分步骤的分子设计推理：

**Step-by-Step Design模板**：

```
[CoT_STEP_BY_STEP]
请按以下步骤进行分子设计推理：

第一步：靶点分析
- 分析{target_name}靶点的结构特征和药效要求
- 识别关键结合位点和必需的药效团

第二步：参考分子分析
- 参考现有{target_name}靶点药物的结构特征
- 识别可保留的活性母核和可优化的取代基

第三步：结构设计
- 提出候选母核结构
- 设计取代基修饰策略
- 评估血脑屏障穿透性

第四步：SMILES生成
- 生成符合以上要求的SMILES字符串
- 验证SMILES的有效性

请逐步输出你的推理过程，最终给出设计的分子SMILES。
```

### 3.3.3 ToT三阶段Prompt设计

Tree-of-Thoughts（思维树）推理Prompt将分子生成过程分解为三个递进阶段：

**阶段1：脚手架提议（Propose Scaffold）**

```yaml
tot_design_nodes:
  propose_scaffold: |
    [FORMAT]
    请为{target_name}靶点设计分子脚手架选项。

    约束条件：
    - 分子量范围：{mw_range}
    - LogP范围：{logp_range}
    - 血脑屏障穿透性：{bbb_requirement}

    请输出3个候选脚手架，包含：
    1. 母核名称（如喹唑啉、吲哚等）
    2. 核心原子组成
    3. 预估分子量
    4. BBB穿透性评估（高/中/低）
    5. 与{target_name}靶点的匹配度评分（1-10）

    [FORMAT]
```

**阶段2：组装策略提议（Propose Assembly）**

```yaml
tot_design_nodes:
  propose_assembly: |
    [FORMAT]
    选定脚手架：{selected_scaffold}（分子量约{scaffold_mw}）
    剩余可用分子量：{remaining_mw}（目标总MW：{target_mw}）

    请为选定的脚手架设计3种组装策略：

    策略X：
    - 提议的取代基类型（如吸电子基团、供电子基团、脂溶性增强基团等）
    - 取代位置（与脚手架的连接位点）
    - 预估分子量贡献
    - 预期药效团增强
    - BBB穿透性影响评估

    [FORMAT]
```

**阶段3：SMILES生成（Generate SMILES）**

```yaml
tot_design_nodes:
  generate_smiles: |
    [FORMAT]
    组装方案已确定：
    - 母核：{selected_scaffold}
    - 组装策略：{assembly_strategy}
    - 弹头类型：{warhead_type}
    - BBB增强基团：{bbb_enhancers}

    目标性质：
    - 目标分子量：{target_mw}
    - 目标LogP：{target_logp_range}
    - 目标TPSA：{target_tpsa_range}

    请生成2-3个符合上述设计的SMILES字符串，并说明每个分子的设计理由。
    [FORMAT]
```

### 3.3.5 结构知识注入器

结构知识注入器（`structural_knowledge_injector.py`）在Prompt生成过程中自动注入分子结构设计的专业知识：

```python
class StructuralKnowledgeInjector:
    """注入分子结构设计专业知识的注入器"""

    # BBB穿透增强基团
    BBB_ENHANCERS = [
        "氟原子（引入亲脂性）",
        "甲氧基（增加分子刚性和亲脂性）",
        "氮原子（减少HBD，提高渗透性）",
        "甲基（增加亲脂性，降低代谢清除）",
    ]

    # 常见PAINS警告结构
    PAINS_PATTERNS = [
        "anilide", "benzopyran", "cinnamate",
        "hetero_cys_ Michael", "hydroxy_pyridine",
    ]

    def inject_structural_context(
        self,
        prompt: str,
        target_name: str,
        constraints: Optional[Dict] = None
    ) -> str:
        """向Prompt中注入结构知识"""
        injected = prompt + "\n\n结构设计知识：\n"
        injected += "BBB穿透增强策略：\n"
        injected += "\n".join(f"- {x}" for x in self.BBB_ENHANCERS)

        injected += "\n\n设计约束：\n"
        injected += "- 避免PAINS警告结构\n"
        injected += "- 合成可及性评分 < 5\n"

        if constraints:
            injected += f"\n具体约束：{constraints}\n"

        return injected
```

## 3.4 多模态分子生成模型

### 3.4.1 Llamole模型架构

Llamole是一个将多模态信息（文本、化学结构、分子图）深度融合的大语言模型，专为逆分子设计与逆合成规划设计。其核心架构由以下组件构成：

**（1）基础语言模型**

Llamole以Qwen2-7B-Instruct作为基础语言模型，该模型具备强大的文本理解和生成能力：
- 参数量：约70亿参数
- 架构：Transformer解码器
- 训练范式：指令微调（Instruction Tuning）
- 上下文长度：支持长达1024个token的生成长度

**（2）Graph Diffusion Transformer（GraphDiT）**

GraphDiT是Llamole的图结构生成核心组件，能够在分子图空间进行扩散式生成：
- 输入：分子图的结构条件（节点类型、边类型）
- 输出：符合化学规则的分子图
- 条件生成：支持基于靶点约束的定向生成
- 去噪过程：T步迭代去噪，逐步从噪声生成有效分子结构

**（3）图神经网络（GNN）编码器/解码器**

GNN组件负责分子图与文本空间的相互转换：
- **编码器**：将SMILES或分子图编码为连续的向量表示，与语言模型的空间对齐
- **解码器**：将语言模型的输出解码为有效的SMILES序列或分子图结构

**（4）图神经网络预测器**

预测器组件评估生成分子的性质：
- **DrugClip Score**：基于多模态对比学习的分子-靶点匹配评分
- 评估输入：分子图结构 + 靶点描述文本
- 输出：0-1之间的相似度评分

**（5）Graph-LM连接器**

连接器模块将语言模型的表示空间与图神经网络的表示空间进行对齐：
- 投影层：将LLM的token嵌入投影到图嵌入空间
- 融合层：文本特征与图特征的交叉注意力融合
- 对齐损失：多模态对比学习对齐

### 3.4.2 GBM领域适配策略

针对GBM药物设计任务，Llamole通过以下策略进行领域适配：

**（1）特殊Token定义**

为分子生成任务定义专用Token，区分不同类型的生成内容：


**LoRA微调的核心原理**：

对于预训练模型的权重矩阵 \( W_0 \in \mathbb{R}^{d \times k} \)，LoRA的更新可以表示为：

$$W = W_0 + \Delta W = W_0 + BA$$

其中：
- \( B \in \mathbb{R}^{d \times r} \) 和 \( A \in \mathbb{R}^{r \times k} \) 是可训练的Low-Rank矩阵
- \( r \ll \min(d, k) \) 是秩（rank）参数，本项目设为16
- 前向传播时：\( h = W_0 x + BAx = (W_0 + BA)x \)

### 3.5.1 分子对接

#### 3.5.1.1 Vina对接工具

AutoDock Vina用于计算生成分子与GBM靶点蛋白的对接亲和力：

**VinaDockingTool核心方法**：

```python
class VinaDockingTool:
    """AutoDock Vina分子对接工具"""

    def __init__(self, receptor_pdb_path: str, center: Tuple[float, float, float],
                 box_size: Tuple[float, float, float] = (22.5, 22.5, 22.5),
                 exhaustiveness: int = 32):
        self.receptor_pdb_path = receptor_pdb_path  # 受体蛋白PDB文件路径
        self.center = center                         # 对接盒子中心坐标
        self.box_size = box_size                    # 对接盒子尺寸（Å）
        self.exhaustiveness = exhaustiveness        # 搜索穷尽度

    def dock(self, smiles: str) -> float:
        """
        对SMILES进行分子对接
        返回：最佳对接分数（kcal/mol），越负表示结合越强
        """
        # Step 1: SMILES转PDBQT
        pdbqt_content = self._smiles_to_pdbqt(smiles)

        # Step 2: 运行Vina对接
        result = subprocess.run(
            ["vina", "--receptor", self.receptor_pdb_path,
             "--ligand", "ligand.pdbqt",
             "--center_x", str(self.center[0]),
             "--center_y", str(self.center[1]),
             "--center_z", str(self.center[2]),
             "--size_x", str(self.box_size[0]),
             "--size_y", str(self.box_size[1]),
             "--size_z", str(self.box_size[2]),
             "--exhaustiveness", str(self.exhaustiveness),
             "--out", "output.pdbqt"],
            capture_output=True, text=True
        )

        # Step 3: 解析结果
        best_score = self._parse_vina_output(result.stdout)
        return best_score

    def _smiles_to_pdbqt(self, smiles: str) -> str:
        """
        SMILES转PDBQT格式（用于AutoDock对接）
        简化实现：使用RDKit生成PDB + 自定义PDBQT转换
        """
        mol = Chem.MolFromSmiles(smiles)
        if mol is None:
            return ""

        # 分配Gasteiger部分电荷
        mol = AllChem.AddHs(mol)
        AllChem.ComputeGasteigerCharges(mol)

        # 转换为PDB格式
        pdb_block = Chem.MolToPDBBlock(mol)

        # 转换为PDBQT格式（添加原子类型和电荷）
        pdbqt_block = self._pdb_to_pdbqt(pdb_block, mol)

        return pdbqt_block

    def _pseudo_dock(self, smiles: str) -> float:
        """
        伪对接方法（当Vina不可用时使用）
        基于分子描述符的启发式评分
        """
        mol = Chem.MolFromSmiles(smiles)
        if mol is None:
            return 0.0

        # 计算基础描述符
        mw = Descriptors.MolWt(mol)
        logp = Descriptors.MolLogP(mol)
        tpsa = Descriptors.TPSA(mol)
        num_rotatable = Descriptors.NumRotatableBonds(mol)

        # 简化的Vina分数估算
        # 经验公式（基于大量对接数据拟合）
        pseudo_vina = (
            -7.0                          # 基准分数
            - 0.02 * (mw - 400)           # MW惩罚
            + 0.3 * (logp - 3.0)         # LogP调整
            + 0.01 * (tpsa - 70)         # TPSA调整
            + 0.1 * (num_rotatable - 3)  # 旋转键惩罚
        )

        # 添加随机扰动模拟真实对接变化
        pseudo_vina += random.gauss(0, 0.3)

        return pseudo_vina
```

### 3.5.2 ADMET预测

#### 3.5.2.1 DILI预测

药物性肝损伤（DILI）预测基于SMARTS模式匹配和分子描述符计算：

**DILICalculator核心规则**：

```python
class ADMETCalculator:
    """ADMET预测计算器"""

    # 高DILI风险警告结构（SMARTS模式）
    DILI_RISK_PATTERNS = [
        # 酰基卤
        ("acyl_halide", "[CX3](=O)[#9,#17,#35,#53]"),
        # 醛类
        ("aldehyde", "[CX3H1]=O"),
        # α,β-不饱和羰基
        ("alpha_beta_unsaturated",
         "[CX3]=[CX3][CX3](=O)"),
        # 环氧化物
        ("epoxide", "[OX2R][CX4R][CX4R]"),
        # 肼类
        ("hydrazine", "[#7][#7]"),
        # Michael受体
        ("michael_acceptor",
         "[CX3]=[CX3]!@[CX3](=O)[OX2]"),
    ]

    # CYP450代谢风险模式
    CYP_RISK_PATTERNS = [
        # CYP1A2底物/抑制剂特征
        ("cyp1a2_risk",
         "[#6]1[#6][#7][#6]2[#6]!@[#8]!@[#6]!@[#6]!@1[#8]2"),  # 二噁英样平面结构
        # CYP3A4底物大环
        ("cyp3a4_substrate",
         "[#6]1[#6][#6][#6][#6][#6]2[#8][#6][#6][#6][#6][#6]1[#6]2"),  # 大环内酯结构
    ]

    def calculate_dili_risk(self, smiles: str) -> float:
        """
        计算DILI风险概率（0-1，越高风险越大）
        """
        mol = Chem.MolFromSmiles(smiles)
        if mol is None:
            return 0.5  # 默认中等风险

        risk_score = 0.0

        # 1. SMARTS模式匹配评分
        for name, pattern in self.DILI_RISK_PATTERNS:
            if mol.HasSubstructMatch(PatternBondPatternRenderer(pattern)):
                risk_score += 0.15  # 每个匹配模式增加0.15风险

        # 2. 分子量评分
        mw = Descriptors.MolWt(mol)
        if mw > 700:
            risk_score += 0.1  # 大分子增加肝毒性风险
        elif mw < 200:
            risk_score += 0.05  # 小分子代谢物可能具有反应性

        # 3. 亲脂性评分（LogP > 4.5增加肝暴露）
        logp = Descriptors.MolLogP(mol)
        if logp > 4.5:
            risk_score += 0.1

        # 4. 苯环羟基化代谢风险（酚类）
        if mol.HasSubstructMatch(Chem.MolFromSmarts("c[OH1]")):
            risk_score += 0.05

        # 5. 苯肼结构（强肝毒性）
        if mol.HasSubstructMatch(Chem.MolFromSmarts("c[NH][NH]c")):
            risk_score += 0.3

        # 归一化到[0, 1]区间
        return min(risk_score, 1.0)
```

#### 3.5.2.2 hERG心脏毒性预测

hERG通道阻断风险（心脏QT延长）是CNS药物的关键安全性指标：

**hERG预测核心规则**：

```python
    # hERG风险结构特征（SMARTS模式）
    HERG_RISK_PATTERNS = [
        # 疏水性平面结构（常见于hERG抑制剂）
        ("planar_aromatic",
         "[a]1[a][a][a][a][a]1"),  # 苯环
        # 含氮芳香杂环
        ("nitrogen_heterocycle",
         "[nR1]1[cR1][cR1][cR1][cR1][cR1]1"),  # 含氮芳环
        # 叔胺或季胺（强碱性，易于结合hERG通道）
        ("tertiary_amine",
         "[NX3H0]([CX4])([CX4])[CX4]"),  # 叔胺
        # 长链疏水基团
        ("hydrophobic_chain",
         "[CX4][CX4][CX4][CX4][CX4][CX4]"),  # 6碳以上烷基链
    ]

    # hERG保护性特征
    HERG_PROTECTIVE_PATTERNS = [
        # 负电荷基团（降低通道结合）
        ("carboxylic_acid", "C(=O)[OH]"),
        ("sulfonamide", "S(=O)(=O)N"),
        # 极性大的末端基团
        ("polar_terminal", "[CX4](=O)[NX3H2]"),  # 酰胺
    ]

    def calculate_herg_risk(self, smiles: str) -> float:
        """
        计算hERG阻断风险（0-1，越高风险越大）
        """
        mol = Chem.MolFromSmiles(smiles)
        if mol is None:
            return 0.5

        risk_score = 0.3  # 基准风险（所有CNS药物）

        # 1. 结构风险模式评分
        risk_matches = sum(
            1 for _, pattern in self.HERG_RISK_PATTERNS
            if mol.HasSubstructMatch(Chem.MolFromSmarts(pattern))
        )
        risk_score += risk_matches * 0.1

        # 2. 保护性特征评分
        protective_matches = sum(
            1 for _, pattern in self.HERG_PROTECTIVE_PATTERNS
            if mol.HasSubstructMatch(Chem.MolFromSmarts(pattern))
        )
        risk_score -= protective_matches * 0.05

        # 3. LogP评分（高亲脂性增加hERG风险）
        logp = Descriptors.MolLogP(mol)
        if logp > 4.0:
            risk_score += 0.1
        elif logp < 2.0:
            risk_score -= 0.05

        # 4. 碱性氮原子评分（质子化后更易结合hERG通道）
        basic_n = mol.GetSubstructMatches(Chem.MolFromSmarts("[#7H2+]"))
        if len(basic_n) > 1:
            risk_score += 0.1
        elif len(basic_n) == 0:
            risk_score -= 0.05

        # 5. 分子刚性和可塑性
        num_rotatable = Descriptors.NumRotatableBonds(mol)
        if num_rotatable < 3:
            risk_score += 0.05  # 高刚性分子可能更适合hERG通道

        # EGFR弹头豁免规则（丙烯酰胺等共价弹头）
        # EGFR抑制剂中的丙烯酰胺弹头不增加hERG风险
        warheads = ["cC(=O)C=Cl", "C(C=NC#N)CC", "cC(=O)C=CN"]  # 简化示例
        for warhead in warheads:
            if mol.HasSubstructMatch(Chem.MolFromSmarts(warhead)):
                risk_score -= 0.1
                break

        return max(0.0, min(risk_score, 1.0))
```

#### 3.5.2.3 BBB血脑屏障通透性预测

BBB通透性预测基于分子性质描述符和Clark公式：

```python
    def calculate_bbb_permeability(self, smiles: str) -> float:
        """
        计算BBB通透性评分（基于Clark公式）
        返回值范围：-3 到 +1（越高越容易穿透BBB）
        """
        mol = Chem.MolFromSmiles(smiles)
        if mol is None:
            return -2.0

        # Clark公式核心描述符
        logp = Descriptors.MolLogP(mol)
        tpsa = Descriptors.TPSA(mol)
        num_hbd = Descriptors.NumHDonors(mol)
        num_hba = Descriptors.NumHAcceptors(mol)

        # Clark BBB评分（经验公式）
        # 公式来源：Clark, D.E. (2003). Rapid Calculation of Polar Surface Area
        # J. Chem. Inf. Comput. Sci. 43: 142-148
        bbb_score = (
            0.193 * logp              # 亲脂性贡献
            - 0.267 * tpsa / 100      # 极性表面积惩罚
            - 0.742 * num_hbd          # 氢键供体惩罚
            + 0.571 * num_hba          # 氢键受体微正贡献（有时）
            - 0.664 * num_rotatable    # 旋转键惩罚
        )

        # BBB分类阈值
        # bbb_score > 0.4: 高通透性（++）
        # 0.4 >= bbb_score > -0.3: 中等通透性（+）
        # -0.3 >= bbb_score > -1.0: 低通透性（-/+）
        # bbb_score <= -1.0: 难以通透（--）

        return bbb_score
```

### 3.5.3 MPO Reward综合评分

MPO（Multi-Parameter Optimization）Reward综合多个药代动力学和药效学参数，计算加权几何平均综合评分：

```python
class MPORewardCalculator:
    """MPO综合评分计算器"""

    # MPO Reward权重配置
    REWARD_WEIGHTS = {
        "vina": 0.30,     # 对接分数权重30%
        "dili": 0.20,     # DILI风险权重20%（越低越好）
        "herg": 0.20,    # hERG风险权重20%（越低越好）
        "bbb": 0.20,     # BBB通透性权重20%（越高越好）
        "physchem": 0.10 # 理化性质权重10%
    }

    # 各指标的归一化参数
    VINA_MIN = -12.0   # 最优对接分数
    VINA_MAX = -4.0    # 勉强可接受的对接分数

    def calculate_mpo_reward(self, eval_result: PhysicalEvaluationResult) -> float:
        """
        计算MPO综合评分（加权几何平均）

        公式：
        Reward = Π_i (Score_i) ^ w_i
        其中 Score_i = normalized_value_of_metric_i, w_i = weight_i

        返回值范围：0 到 1（越高越好）
        """
        # 1. Vina分数归一化（越负越好，归一化到[0,1]）
        vina_norm = self._normalize_vina(eval_result.vina_score)

        # 2. DILI风险归一化（越低越好，归一化到[0,1]）
        dili_norm = self._normalize_risk(eval_result.dili_risk)

        # 3. hERG风险归一化（越低越好，归一化到[0,1]）
        herg_norm = self._normalize_risk(eval_result.herg_risk)

        # 4. BBB通透性归一化（越高越好，归一化到[0,1]）
        bbb_norm = self._normalize_bbb(eval_result.bbb_permeability)

        # 5. 理化性质归一化
        physchem_norm = self._normalize_physchem(eval_result)

        # 加权几何平均
        weights = list(self.REWARD_WEIGHTS.values())
        scores = [vina_norm, dili_norm, herg_norm, bbb_norm, physchem_norm]

        # 避免0值导致乘积为0，添加极小epsilon
        epsilon = 1e-6
        scores = [max(s, epsilon) for s in scores]

        # 几何平均：乘积的权重次方根
        mpo_reward = 1.0
        for score, weight in zip(scores, weights):
            mpo_reward *= (score ** weight)

        return mpo_reward

    def _normalize_vina(self, vina_score: float) -> float:
        """Vina分数归一化"""
        if vina_score <= self.VINA_MIN:
            return 1.0
        elif vina_score >= self.VINA_MAX:
            return 0.0
        else:
            return (self.VINA_MAX - vina_score) / (self.VINA_MAX - self.VINA_MIN)

    def _normalize_risk(self, risk: float) -> float:
        """风险值归一化（风险越低越好）"""
        # 0.0对应最高风险，1.0对应最低风险
        return 1.0 - risk

    def _normalize_bbb(self, bbb_score: float) -> float:
        """BBB评分归一化"""
        # Clark BBB评分范围约[-3, +1]
        if bbb_score >= 0.4:
            return 1.0
        elif bbb_score <= -1.0:
            return 0.0
        else:
            return (bbb_score + 1.0) / 1.4

    def _normalize_physchem(self, eval_result: PhysicalEvaluationResult) -> float:
        """
        理化性质综合归一化
        综合评估MW、LogP、TPSA、氢键数等
        """
        mol = Chem.MolFromSmiles(eval_result.smiles)
        if mol is None:
            return 0.5

        mw = Descriptors.MolWt(mol)
        logp = Descriptors.MolLogP(mol)
        tpsa = Descriptors.TPSA(mol)
        num_rotatable = Descriptors.NumRotatableBonds(mol)

        # Lipinski五规则评分
        score = 1.0

        # MW惩罚（理想范围300-500）
        if mw > 600:
            score -= 0.3
        elif mw > 500:
            score -= 0.1

        # LogP惩罚（理想范围1-4）
        if logp > 5 or logp < 0:
            score -= 0.2
        elif logp > 4 or logp < 1:
            score -= 0.1

        # TPSA惩罚（理想范围40-120）
        if tpsa > 140:
            score -= 0.2
        elif tpsa > 120:
            score -= 0.1

        # 旋转键惩罚（理想范围<8）
        if num_rotatable > 10:
            score -= 0.2
        elif num_rotatable > 8:
            score -= 0.1

        return max(0.0, min(score, 1.0))
```

```python
        "logp": {
            "min": 0,
            "max": 5,
            "description": "LogP必须在0-5范围内"
        },
    }

    def check_hard_cutoffs(self, eval_result: PhysicalEvaluationResult) -> Tuple[bool, List[str]]:
        """
        检查分子是否通过硬剪枝
        返回：(是否通过, 未通过的原因列表)
        """
        failed_reasons = []
        mol = Chem.MolFromSmiles(eval_result.smiles)

        if mol is None:
            return False, ["Invalid SMILES"]

        # 检查Vina分数
        if eval_result.vina_score >= self.HARD_CUTOFFS["vina_score"]["threshold"]:
            failed_reasons.append(
                f"Vina={eval_result.vina_score:.2f} >= -5.0 (HARD CUTOFF)"
            )

        # 检查DILI风险
        if eval_result.dili_risk >= self.HARD_CUTOFFS["dili_risk"]["threshold"]:
            failed_reasons.append(
                f"DILI={eval_result.dili_risk:.3f} >= 0.95 (HARD CUTOFF)"
            )

        # 检查hERG风险
        if eval_result.herg_risk >= self.HARD_CUTOFFS["herg_risk"]["threshold"]:
            failed_reasons.append(
                f"hERG={eval_result.herg_risk:.3f} >= 0.95 (HARD CUTOFF)"
            )

        # 检查分子量
        mw = Descriptors.MolWt(mol)
        if mw < self.HARD_CUTOFFS["molecular_weight"]["min"]:
            failed_reasons.append(f"MW={mw:.1f} < 300 (HARD CUTOFF)")
        if mw > self.HARD_CUTOFFS["molecular_weight"]["max"]:
            failed_reasons.append(f"MW={mw:.1f} > 600 (HARD CUTOFF)")

        # 检查TPSA
        tpsa = Descriptors.TPSA(mol)
        if tpsa < self.HARD_CUTOFFS["tpsa"]["min"]:
            failed_reasons.append(f"TPSA={tpsa:.1f} < 40 (HARD CUTOFF)")
        if tpsa > self.HARD_CUTOFFS["tpsa"]["max"]:
            failed_reasons.append(f"TPSA={tpsa:.1f} > 140 (HARD CUTOFF)")

        # 检查LogP
        logp = Descriptors.MolLogP(mol)
        if logp < self.HARD_CUTOFFS["logp"]["min"]:
            failed_reasons.append(f"LogP={logp:.2f} < 0 (HARD CUTOFF)")
        if logp > self.HARD_CUTOFFS["logp"]["max"]:
            failed_reasons.append(f"LogP={logp:.2f} > 5 (HARD CUTOFF)")

        passed = len(failed_reasons) == 0
        return passed, failed_reasons
```

#### 3.5.4.2 Delta Scoring机制

Delta Scoring用于在ToT搜索过程中，动态调整毒性评估的严格程度，以避免过度剪枝有潜力的分子：

```python
    # Delta Scoring配置
    DELTA_SCORING = {
        "enabled": True,              # 是否启用Delta Scoring
        "toxicity_relaxation": 0.05,  # 毒性放宽阈值（5%）
        "max_iterations": 3,          # 最大迭代次数
    }

    def apply_delta_scoring(
        self,
        current_result: PhysicalEvaluationResult,
        parent_result: Optional[PhysicalEvaluationResult],
        depth: int
    ) -> Tuple[float, bool]:
        """
        应用Delta Scoring机制，动态放宽剪枝严格度

        核心思想：
        如果当前分子的毒性增量（相对于父分子）小于DELTA_SCORING["toxicity_relaxation"]，
        则适当放宽毒性阈值，以允许探索更多化学空间。

        参数：
        - current_result: 当前分子的评估结果
        - parent_result: 父分子（ToT树中的上一级分子）的评估结果
        - depth: ToT搜索深度（越深可接受的放宽越大）

        返回：(调整后的毒性评分, 是否应用了Delta Scoring)
        """
        if not self.DELTA_SCORING["enabled"] or parent_result is None:
            return current_result.dili_risk, False

        # 计算毒性增量
        delta_dili = current_result.dili_risk - parent_result.dili_risk
        delta_herg = current_result.herg_risk - parent_result.herg_risk

        # 如果毒性增量很小，应用Delta Scoring
        if delta_dili < self.DELTA_SCORING["toxicity_relaxation"]:
            # 毒性放宽因子随深度增加
            relaxation_factor = min(depth * 0.02, 0.1)
            adjusted_dili = parent_result.dili_risk + (
                delta_dili * (1 - relaxation_factor)
            )
            return adjusted_dili, True

        if delta_herg < self.DELTA_SCORING["toxicity_relaxation"]:
            relaxation_factor = min(depth * 0.02, 0.1)
            adjusted_herg = parent_result.herg_risk + (
                delta_herg * (1 - relaxation_factor)
            )
            return adjusted_herg, True

        return current_result.dili_risk, False
```

### 3.5.5 物理评估管线集成

GBMPhysicalEvaluator是物理评估管线的顶层集成类：

```python
@dataclass
class PhysicalEvaluationResult:
    """物理评估结果数据类"""
    smiles: str
    vina_score: float              # AutoDock Vina对接分数
    dili_risk: float               # DILI风险（0-1）
    herg_risk: float              # hERG风险（0-1）
    bbb_permeability: float       # BBB通透性评分
    mw: float                      # 分子量
    logp: float                    # LogP
    tpsa: float                    # TPSA
    num_rotatable: int             # 旋转键数
    mpo_reward: float              # MPO综合评分
    passed_hard_cutoffs: bool      # 是否通过硬剪枝
    cutoff_failures: List[str]     # 未通过的剪枝原因


class GBMPhysicalEvaluator:
    """GBM物理评估管线集成类"""

    def __init__(
        self,
        receptor_pdb_path: str,
        vina_center: Tuple[float, float, float],
        enable_pseudo_dock: bool = False
    ):
        self.vina_tool = VinaDockingTool(
            receptor_pdb_path=receptor_pdb_path,
            center=vina_center,
            box_size=(22.5, 22.5, 22.5),
            exhaustiveness=32
        )
        self.admet_calc = ADMETCalculator()
        self.mpo_calc = MPORewardCalculator()
        self.enable_pseudo_dock = enable_pseudo_dock

    def evaluate(self, smiles: str,
                 parent_smiles: Optional[str] = None,
                 tot_depth: int = 0) -> PhysicalEvaluationResult:
        """
        对SMILES进行完整的物理评估

        评估流程：
        1. 有效性检查（SMILES解析）
        2. ADMET预测（DILI、hERG、BBB）
        3. Vina对接（分子对接）
        4. 硬剪枝检查
        5. MPO Reward计算
        6. Delta Scoring（可选）
        """
        mol = Chem.MolFromSmiles(smiles)
        if mol is None:
            return PhysicalEvaluationResult(
                smiles=smiles,
                vina_score=0.0, dili_risk=1.0, herg_risk=1.0,
                bbb_permeability=-3.0, mw=0, logp=0, tpsa=0,
                num_rotatable=0, mpo_reward=0.0,
                passed_hard_cutoffs=False,
                cutoff_failures=["Invalid SMILES"]
            )

        # Step 1: ADMET预测
        dili_risk = self.admet_calc.calculate_dili_risk(smiles)
        herg_risk = self.admet_calc.calculate_herg_risk(smiles)
        bbb_permeability = self.admet_calc.calculate_bbb_permeability(smiles)

        # Step 2: Vina对接
        if self.enable_pseudo_dock:
            vina_score = self.vina_tool._pseudo_dock(smiles)
        else:
            vina_score = self.vina_tool.dock(smiles)

        # Step 3: 计算描述符
        mw = Descriptors.MolWt(mol)
        logp = Descriptors.MolLogP(mol)
        tpsa = Descriptors.TPSA(mol)
        num_rotatable = Descriptors.NumRotatableBonds(mol)

        # Step 4: 构建评估结果
        eval_result = PhysicalEvaluationResult(
            smiles=smiles,
            vina_score=vina_score,
            dili_risk=dili_risk,
            herg_risk=herg_risk,
            bbb_permeability=bbb_permeability,
            mw=mw, logp=logp, tpsa=tpsa,
            num_rotatable=num_rotatable,
            mpo_reward=0.0,  # 待计算
            passed_hard_cutoffs=False,
            cutoff_failures=[]
        )

        # Step 5: 硬剪枝检查
        passed, failures = self.mpo_calc.check_hard_cutoffs(eval_result)
        eval_result.passed_hard_cutoffs = passed
        eval_result.cutoff_failures = failures

        # Step 6: MPO Reward计算
        eval_result.mpo_reward = self.mpo_calc.calculate_mpo_reward(eval_result)

        # Step 7: Delta Scoring（如果提供了父分子）
        if parent_smiles and tot_depth > 0:
            parent_eval = self.evaluate(parent_smiles)
            adjusted_dili, applied = self.mpo_calc.apply_delta_scoring(
                eval_result, parent_eval, tot_depth
            )
            if applied:
                eval_result.dili_risk = adjusted_dili
                # 重新计算MPO Reward
                eval_result.mpo_reward = self.mpo_calc.calculate_mpo_reward(eval_result)

        return eval_result

    def build_feedback_text(self, eval_result: PhysicalEvaluationResult) -> str:
        """
        将评估结果转换为自然语言反馈文本，
        用于注入到Prompt中指导下一轮生成
        """
        mol = Chem.MolFromSmiles(eval_result.smiles)
        mol_name = mol.GetProp("_Name") if mol.HasProp("_Name") else "Unknown"

        feedback = f"""分子: {mol_name}
SMILES: {eval_result.smiles}

=== 物理评估结果 ===

1. 对接评分: {eval_result.vina_score:.2f} kcal/mol
   评估: {"✓ 良好" if eval_result.vina_score < -7.0 else "⚠ 需优化" if eval_result.vina_score < -5.0 else "✗ 不合格"}

2. DILI风险: {eval_result.dili_risk:.3f}
   评估: {"✓ 低风险" if eval_result.dili_risk < 0.3 else "⚠ 中风险" if eval_result.dili_risk < 0.7 else "✗ 高风险"}

3. hERG风险: {eval_result.herg_risk:.3f}
   评估: {"✓ 低风险" if eval_result.herg_risk < 0.3 else "⚠ 中风险" if eval_result.herg_risk < 0.7 else "✗ 高风险"}

4. BBB通透性: {eval_result.bbb_permeability:.2f}
   评估: {"✓ 高通透" if eval_result.bbb_permeability > 0.0 else "⚠ 中通透" if eval_result.bbb_permeability > -0.5 else "✗ 低通透"}

5. 理化性质:
   - 分子量: {eval_result.mw:.1f} (理想: 300-500)
   - LogP: {eval_result.logp:.2f} (理想: 1.0-4.0)
   - TPSA: {eval_result.tpsa:.1f} Å² (理想: 40-120)

6. MPO综合评分: {eval_result.mpo_reward:.4f}

7. 硬剪枝状态: {"✓ 通过" if eval_result.passed_hard_cutoffs else "✗ 未通过"}
"""

        if eval_result.cutoff_failures:
            feedback += "\n未通过原因：\n" + "\n".join(f"  - {f}" for f in eval_result.cutoff_failures)

        return feedback
```

## 3.6 ToT三阶段搜索算法

### 3.6.1 算法概述

Tree-of-Thoughts（思维树）搜索算法将分子生成过程建模为一棵多叉树，通过广度优先搜索（BFS）在三个递进阶段探索化学空间：

```
                    [ROOT: GBM Target Selection]
                              |
                    ┌─────────┼─────────┐
                    ▼         ▼         ▼
            [Stage 1: Scaffold Proposal]
              BFS宽度=3，选择Top-1
                    |
            ┌───────┼───────┐
            ▼       ▼       ▼
    [Scaffold A][Scaffold B][Scaffold C]
            |
            ▼
    [Stage 2: Assembly Strategy]
       BFS宽度=3，选择Top-1
            |
    ┌───────┼───────┐
    ▼       ▼       ▼
[Strat 1][Strat 2][Strat 3]
    |
    ▼
[Stage 3: SMILES Generation]
   采样生成N个SMILES
    |
    ▼
[Physical Evaluation]
   Vina + ADMET + MPO
    |
    ▼
[Hard Cutoffs + Ranking]
```

### 3.6.2 算法伪代码

```python
def tot_search(
    target_name: str,
    constraints: Dict,
    max_depth: int = 3,
    breadth_per_stage: int = 3,
    num_smiles_per_leaf: int = 5,
    physical_evaluator: GBMPhysicalEvaluator,
    prompt_generator: GBMPromptGenerator
) -> List[Tuple[str, PhysicalEvaluationResult]]:
    """
    ToT三阶段搜索算法

    参数：
    - target_name: 靶点名称（如"EGFR"）
    - constraints: 分子约束条件
    - max_depth: 最大搜索深度（默认3）
    - breadth_per_stage: 每阶段广度（默认3）
    - num_smiles_per_leaf: 每叶节点生成SMILES数
    - physical_evaluator: 物理评估器
    - prompt_generator: Prompt生成器

    返回：排序后的候选分子列表 [(smiles, eval_result), ...]
    """

    # Step 0: 初始化
    all_candidates = []
    domain_prompt = prompt_generator.generate_domain_prompt(
        target_name, constraints
    )

    # 预先生成参考分子（用于Few-shot学习）
    reference_smiles = knowledge_base.get_reference_molecules(top_k=10)

    # ========== Stage 1: Scaffold Proposal ==========
    # 状态：{target_name, mw_range, bbb_requirement, logp_range}
    scaffold_state = {
        "target_name": target_name,
        "mw_range": constraints.get("mw_range", "300-500"),
        "bbb_requirement": "high",
        "logp_range": constraints.get("logp_range", "2.0-4.0")
    }

    scaffold_prompt = prompt_generator.build_tot_propose_prompt(
        domain_prompt, scaffold_state, "scaffold"
    )
    scaffold_prompt += f"\n\n参考分子：{', '.join(reference_smiles[:3])}"

    # 采样多个脚手架提议
    scaffold_responses = model.sample(
        scaffold_prompt,
        num_samples=breadth_per_stage,
        temperature=0.8
    )

    # 解析脚手架提议，选择Top-1
    scaffolds = []
    for resp in scaffold_responses:
        scaffold = parse_scaffold_from_response(resp)
        if scaffold:
            scaffolds.append(scaffold)

    best_scaffold = select_top_k(scaffolds, k=1)[0]

    # ========== Stage 2: Assembly Strategy ==========
    # 状态：{selected_scaffold, scaffold_mw, remaining_mw, target_mw}
    assembly_state = {
        "selected_scaffold": best_scaffold["name"],
        "scaffold_mw": best_scaffold["estimated_mw"],
        "remaining_mw": constraints.get("target_mw", 500) - best_scaffold["estimated_mw"],
        "target_mw": constraints.get("target_mw", 500)
    }

    assembly_prompt = prompt_generator.build_tot_propose_prompt(
        domain_prompt, assembly_state, "assembly"
    )

    # 采样多个组装策略
    assembly_responses = model.sample(
        assembly_prompt,
        num_samples=breadth_per_stage,
        temperature=0.7
    )

    # 解析组装策略，选择Top-1
    assembly_strategies = []
    for resp in assembly_responses:
        strategy = parse_assembly_from_response(resp)
        if strategy:
            assembly_strategies.append(strategy)

    best_strategy = select_top_k(assembly_strategies, k=1)[0]

    # ========== Stage 3: SMILES Generation ==========
    # 状态：{selected_scaffold, assembly_strategy, warhead_type, ...}
    smiles_state = {
        "selected_scaffold": best_scaffold["name"],
        "assembly_strategy": best_strategy["name"],
        "warhead_type": best_strategy.get("warhead_type", "acrylamide"),
        "bbb_enhancers": best_strategy.get("bbb_enhancers", "fluorine, methoxy"),
        "target_mw": constraints.get("target_mw", 500),
        "target_logp_range": constraints.get("logp_range", "2.0-4.0"),
        "target_tpsa_range": constraints.get("tpsa_range", "40-120 Å²")
    }

    smiles_prompt = prompt_generator.build_tot_propose_prompt(
        domain_prompt, smiles_state, "smiles"
    )

    # 采样生成多个SMILES
    smiles_responses = model.sample(
        smiles_prompt,
        num_samples=num_smiles_per_leaf,
        temperature=0.9  # 高温度以增加多样性
    )

    # 解析SMILES
    all_smiles = []
    for resp in smiles_responses:
        parsed_smiles = parse_smiles_from_response(resp)
        all_smiles.extend(parsed_smiles)

    # ========== Physical Evaluation ==========
    # 对所有候选SMILES进行物理评估
    for smiles in all_smiles:
        eval_result = physical_evaluator.evaluate(smiles)

        # 硬剪枝：仅保留通过硬剪枝的分子
        if eval_result.passed_hard_cutoffs:
            all_candidates.append((smiles, eval_result))

    # ========== Ranking ==========
    # 按MPO Reward降序排序
    ranked_candidates = sorted(
        all_candidates,
        key=lambda x: x[1].mpo_reward,
        reverse=True
    )

    return ranked_candidates
```

### 3.6.3 ToT与物理评估的闭环集成

ToT搜索算法与物理评估管线形成闭环，通过迭代优化不断提升生成分子的质量：

```python
def iterative_tot_with_feedback(
    target_name: str,
    constraints: Dict,
    max_iterations: int = 3,
    candidates_per_iteration: int = 10
) -> List[Tuple[str, PhysicalEvaluationResult]]:
    """
    带反馈注入的迭代ToT搜索

    核心思想：
    1. 初始ToT生成候选分子
    2. 物理评估获得反馈
    3. 将反馈注入Prompt，指导下一轮生成
    4. 重复直到收敛或达到最大迭代次数
    """
    best_candidates = []
    best_smiles = set()

    for iteration in range(max_iterations):
        # 构建带反馈的Prompt
        if best_candidates:
            # 取当前最佳候选作为种子
            best_smiles_list = [c[0] for c in best_candidates[:3]]

            # 获取反馈文本
            feedback_texts = []
            for smiles, eval_result in best_candidates[:3]:
                feedback_texts.append(
                    physical_evaluator.build_feedback_text(eval_result)
                )

            # 构建带反馈的Prompt
            combined_feedback = "\n\n---\n\n".join(feedback_texts)
            domain_prompt = prompt_generator.build_feedback_injected_prompt(
                domain_prompt=domain_prompt,
                physical_feedback=combined_feedback,
                previous_smiles="\n".join(best_smiles_list),
                next_action_hint="请基于上述物理评估反馈，生成改进的候选分子。"
            )
        else:
            # 第一轮：无反馈的初始生成
            domain_prompt = prompt_generator.generate_domain_prompt(
                target_name, constraints
            )

        # ToT搜索
        candidates = tot_search(
            target_name=target_name,
            constraints=constraints,
            max_depth=3,
            breadth_per_stage=3,
            num_smiles_per_leaf=5,
            physical_evaluator=physical_evaluator,
            prompt_generator=prompt_generator,
            domain_prompt=domain_prompt  # 传入更新后的Prompt
        )

        # 去重（避免重复生成相同分子）
        new_candidates = [(s, e) for s, e in candidates if s not in best_smiles]
        best_candidates.extend(new_candidates)
        best_smiles.update([s for s, _ in new_candidates])

        # 按MPO Reward重排序
        best_candidates = sorted(
            best_candidates,
            key=lambda x: x[1].mpo_reward,
            reverse=True
        )[:candidates_per_iteration]

        # 早停检查：如果Top-1候选的MPO Reward不再提升，停止迭代
        if iteration > 0 and best_candidates:
            current_best_reward = best_candidates[0][1].mpo_reward
            previous_best_reward = previous_best_rewards[-1]
            if abs(current_best_reward - previous_best_reward) < 1e-4:
                print(f"Early stopping at iteration {iteration}")
                break

    return best_candidates
```
